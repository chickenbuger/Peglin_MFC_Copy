# Enemy Expansion v1 · ImageGen prompts

Built-in ImageGen을 사용해 기존 몬스터 스프라이트 3종을 스타일 참고 이미지로 제공하고, 아래 신규 실루엣을 투명 PNG로 생성했다.

## Thornback Wolf

- 어두운 동굴 판타지의 4족 늑대형 몬스터
- 나무껍질 갑옷, 가시 덩굴 갈기, 이끼, 호박색 수정 발톱과 눈
- 기존 캐릭터와 동일한 수작업 페인팅 스타일, 좌측을 향한 3/4 전신 구도
- 투명 배경, 텍스트·UI·프레임·워터마크 제외

## Azure Cave Wisp

- 둥근 청색 불꽃 몸과 부유하는 석재 고리, 청록 수정 코어를 가진 동굴 정령
- 남색·청록색 중심에 호박색 눈 포인트
- 기존 캐릭터와 동일한 수작업 페인팅 스타일, 좌측을 향한 3/4 전신 구도
- 투명 배경, 텍스트·UI·프레임·워터마크 제외
