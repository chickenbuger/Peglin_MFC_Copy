# Reward Item Icons v1

Version 7.7에서 생성한 오브·유물 보상 아이콘의 제작 기록입니다. 모든 원본은 built-in `imagegen`으로 생성한 투명 PNG이며, `tools/Build-Assets.ps1`이 96×96 24-bit BMP와 마젠타 투명 키로 변환합니다.

## 공통 규칙

- 화풍: 네이비 동굴과 앰버 크리스털 조명에 맞춘 hand-painted premium indie dark-fantasy
- 구도: 아이콘 한 개를 정중앙에 배치하고 작은 크기에서도 실루엣이 구분되도록 제작
- 출력: genuinely transparent background, clean alpha edges
- 제외: 텍스트, 테두리, 배경 장면, 플랫폼, 로고, 워터마크
