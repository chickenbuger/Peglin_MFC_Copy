## P0 — Sprint 3 완료 필수 후보

- [x] 피해·점수 애니메이션과 사운드 피드백 — Version 3.1
  - 이유: 점수와 특수 페그 규칙은 계산되지만 순간적인 효과를 텍스트만으로 추적하기 어렵다.
  - 완료 기준: 피해·점수·콤보와 특수 효과가 시각·청각적으로 구분되며 음소거를 지원한다.
- [x] 조준 예상선과 발사 세기 시각화 — Version 3.2
  - 이유: 현재 드래그 입력은 방향과 힘을 발사 전에 정확히 비교하기 어렵다.
  - 완료 기준: 조준 중 예상 방향과 정규화한 힘이 표시되고 0 길이 취소·캡처 안전성이 유지된다.
- [ ] 스테이지 선택과 결과 화면
  - 이유: `stage-1`과 `stage-2` 데이터는 존재하지만 게임 안에서 선택하거나 결과를 비교하는 화면이 없다.
  - 완료 기준: 검증된 스테이지만 선택할 수 있고 승패·점수·최고 콤보 결과를 한 번만 표시한다.
- [ ] 난이도와 접근성 옵션
  - 이유: 스테이지 규칙과 시각 효과를 사용자 환경에 맞추는 설정 경로가 필요하다.
  - 완료 기준: 최소한 난이도, 음소거와 핵심 색상 구분 옵션을 제공하고 새 게임·재실행 동작을 정의한다.
