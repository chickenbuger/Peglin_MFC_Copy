## 최종 빌드·자동화 테스트

- Windows SDK `10.0.26100.0`, MSVC v143, C++20, `/W4` 기준을 유지했다.
- Debug/Release × x64/x86 네 구성에서 앱과 `PeglinCoreTests`를 최종 빌드했다.
- 네 구성 모두 오류 0개, 프로젝트 자체 경고 0개다.
- 각 테스트 실행 파일이 201개 검증을 통과해 총 `804 PASS / 0 FAIL`을 기록했다.
- 마지막 빌드와 테스트 직후 `git status`에 소스나 빌드 생성물 변경이 나타나지 않았다.

## 실제 입력·플레이 회귀

- Release x64에서 같은 위치 클릭·해제가 발사로 이어지지 않고 다음 정상 발사가 가능했다.
- 특수 페그를 포함한 발사에서 10개 적중, 몬스터 체력 `20→9`, 총점 5,800과 최고 콤보 10을 확인했다.
- 일시정지·재개와 F5 초기화가 정상 동작했으며 F5 뒤에도 이미 확정된 총점 5,800은 유지됐다.
- 다음 발사로 몬스터를 쓰러뜨렸고 최종 점수 10,300과 `Game Clear!!` 대화상자 하나만 표시됐다.
- 확인 버튼을 한 번 누른 뒤 중첩 대화상자 없이 플레이어 100, 몬스터 20, 점수 0, 페그 48개의 새 게임 상태로 복귀했다.
- 페그를 피하는 수직 발사에서 1~8턴은 적 이동만 일어났고 플레이어 체력은 100으로 유지됐다.
- 9~13턴에는 피해 20씩 적용되어 플레이어 체력이 `100→80→60→40→20→0`으로 감소했다.
- `Game Over!!` 대화상자도 한 번만 표시됐고 확인 후 체력·점수·페그가 정상 초기화됐다.
- 전체 과정에서 ASSERT, 예외, 접근 위반과 잔류 마우스 캡처가 없었으며 게임 창을 정상 종료했다.

## GDI 10분 안정성

- Release x64를 30초 워밍업한 뒤 실제 발사·승리·패배·재시작을 수행하며 1분 간격으로 0~10분 표본을 측정했다.
- GDI 객체 표본: `31, 31, 34, 34, 34, 34, 34, 34, 34, 34, 34`
- 마지막 값은 기준보다 +3으로 허용치 +5 이하다.
- 2분차 이후 아홉 표본이 34개로 고정되어 후반 지속 상승이 없다.
- 모든 표본에서 프로세스 `Responding=True`였다.

Sprint 2의 P0 네 항목과 빌드·자동화·입력·승패·종료 메시지·GDI 검증 게이트를 모두 완료했다. `Next_Version_Plan_3.md`에는 다음 후보만 정리했으며 Sprint 3 구현은 시작하지 않는다.
