# Version 1.5 — 핵심 물리·턴 자동화 테스트

## 버전 정보

| 항목 | 값 |
| --- | --- |
| 버전 | Version 1.5 |
| 스프린트 | Sprint 1 |
| 작업일 | 2026-08-29 (Asia/Seoul) |
| 목적 | 물리와 게임 상태 전이의 핵심 수용 기준을 네 빌드 구성에서 반복 검증 |
| 판정 | **완료 — 네 구성에서 각 42개, 총 168개 검증 통과** |

## 변경 사항

- 솔루션에 `PeglinCoreTests` 콘솔 테스트 프로젝트를 추가했다.
- 테스트 프로젝트도 Windows SDK `10.0.26100.0`, MSVC v143, C++20, 동적 MFC와 `/W4`를 사용한다.
- 외부 테스트 프레임워크 없이 실패 개수와 종료 코드로 CI 및 명령줄 실행이 가능한 테스트 러너를 구성했다.
- Debug/Release × x64/x86의 솔루션 빌드에 앱과 테스트 실행 파일이 함께 생성된다.

## 자동화 검증 범위

- 0 길이 발사 취소, 조준 상태 유지, 비활성·속도 0 상태
- 왼쪽 벽과 천장 겹침 보정, 접근 속도 반사, 접선 속도 유지
- 페그 1개 제거, 법선 반발계수, 접선 보존, 충돌 반경 밖 겹침 보정
- 제거된 페그 1개의 피해가 적 체력에 정확히 1회 적용
- 화면 이탈 후 적 턴 수와 위치 전진, 피해 없는 턴 처리
- 치명적 페그 피해의 `Victory` 결과와 상태
- 플레이어 공격 임계점의 `Defeat` 결과, 상태와 단일 피해
- 유효·무효 상태 전이, 반발계수 범위 제한, 멀어지는 속도 무반사

## 검증 결과

- 최초 실행에서 외벽에 가까운 첫 페그를 사용해 페그 반사 직후 벽 반사가 연쇄되는 테스트 격리 문제를 발견했다.
- 내부 페그를 선택하도록 테스트를 수정하고 실패 상태는 커밋하지 않았다.
- Debug x64, Release x64, Debug x86, Release x86 모두 각각 42개 검증 통과, 종료 코드 0.
- 네 솔루션 구성 모두 앱과 테스트 프로젝트가 오류 0개, 자체 코드 경고 0개로 빌드됐다.

Sprint 1 P0의 상태 머신, 모델 분리, 벡터 타입과 충돌 반사가 자동 회귀 기준으로 고정됐다. 다음 단계에서는 P1의 데이터 기반 레이아웃, 플레이 피드백과 재현 가능한 보드 생성을 진행한다.
