## ImageGen 자산

- 사용자가 지정한 `imagegen` 스킬과 OpenAI built-in 생성 모드를 사용했다.
- 용도는 `stylized-concept`이며 5:4 판타지 동굴·숲 테두리, 중앙 스테이지 공간과 좌우 보조 패널을 요청했다.
- 이미지 안에는 글자·숫자·로고·워터마크·캐릭터를 생성하지 않고 모든 문구는 MFC가 그리도록 분리했다.
- 생성 PNG를 내용 변경 없이 1000×800 24-bit BMP로 변환해 `IDB_UI_ADVENTURE_FRAME` Windows 리소스로 포함했다.
- 앱은 비트맵을 창 생성 시 한 번만 로드하고 종료 시 해제하며 매 프레임 소스 DC의 이전 비트맵을 복원한다.
- 최종 프롬프트와 원본·프로젝트 경로는 `res/ui-adventure-frame-v1.prompt.md`에 보존했다.

## 공통 UI 시스템

- `UiRenderer`에 배경 확대, 둥근 패널, 선택 강조, 글자와 키 안내 그리기를 통합했다.
- 각 함수는 `SaveDC/RestoreDC`와 선택 객체 복원을 사용해 GDI 수명을 보존한다.
- 실제 클라이언트 영역을 기준으로 배경을 확대해 메뉴·상태 표시줄이 있는 창에서도 하단이 잘리지 않게 했다.
- 스테이지 선택, 장비, 옵션과 결과 화면이 같은 팔레트·패널·제목·키 안내를 재사용한다.

## 상호작용

- 스테이지 선택에서 `↑/↓` 순환 선택, `Enter` 시작과 기존 `1/2/3` 빠른 시작을 지원한다.
- 선택 카드는 금색 테두리로 포커스를 명확히 표시한다.
- 좌측에 현재 오브·유물을, 우측에 난이도·사운드·접근성 설정을 항상 요약한다.
- `[L]` 장비 화면을 추가했다.
  - `[1-3]`: Traveler/Iron/Echo Orb 선택
  - `[4-6]`: Combo Lantern/Thorn Charm/Bark Guard 획득
  - `[X]`: 오브·유물 기본 상태 초기화
  - `[B]` 또는 `Esc`: 스테이지 화면 복귀
- 장비 카드는 현재 선택·최대 중첩을 테두리로 표시하고 개별·최종 배율과 성공·한도 메시지를 보여 준다.
- 플레이 HUD에 현재 오브와 유물 요약을 추가했다.

## 실제 화면 검증

- Debug x64에서 생성 배경과 스테이지 3개, 좌우 패널 및 텍스트 겹침 여부를 확인했다.
- `↓` 입력으로 두 번째 카드 포커스 이동, `Enter`로 Dense Cavern 시작을 확인했다.
- Iron Orb 선택과 Combo Lantern 획득 후 장비 화면·스테이지 요약·게임 HUD에 상태가 유지됐다.
- 첫 실행에서 800px 고정 하단 안내가 실제 약 700px 클라이언트 영역에서 잘리는 문제를 발견했다.
- 실제 클라이언트 크기와 y=640~690 배치로 수정 후 스테이지·장비·옵션 화면에서 하단 키 안내가 모두 표시됐다.
- 창 종료 뒤 게임 프로세스가 남지 않았다.
