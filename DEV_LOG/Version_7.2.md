## 개선 이유

기존 적 ID는 7개였지만 실제 실루엣은 두꺼비·박쥐·주술사 3종뿐이라 스테이지가 달라도 시각적 반복이 컸다. 새 실루엣과 고유 색을 가진 몬스터를 추가해 분기 경로별 적 구성이 눈에 띄게 달라지도록 했다.

## 구현 내용

- ImageGen 기반 `Thornback Wolf`와 `Azure Cave Wisp` 투명 PNG 스프라이트를 제작했다.
- 런타임용 24-bit BMP와 MFC 리소스 ID를 추가하고 생성 프롬프트를 저장했다.
- `EnemyVisualKind`를 3종에서 5종으로 확장했다.
- 외부 스테이지 파서가 `ThornbackWolf`, `AzureWisp` 값을 검증해 읽도록 했다.
- 내장·외부 스테이지 4~8의 로스터에 새 몬스터를 분산 배치했다.
- 게임플레이 효과 카탈로그에 `thornback-wolf`, `azure-wisp` 안정 ID를 추가해 전체 적 ID를 9개로 확장했다.
- 잘못된 시각 타입 거부와 외부 콘텐츠 전체 복구 규칙은 그대로 유지했다.
