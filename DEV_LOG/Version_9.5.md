## 개선 이유

이 프로젝트는 MFC·Win32·XInput·XAudio2를 사용하는 Windows 전용 게임이지만 일부 저장소와 오디오 경로 코드에는 비-Windows 환경을 가정한 조건부 컴파일과 범용 파일 교체 대체 경로가 남아 있었다. 지원하지 않는 플랫폼의 분기는 실제 동작 경로를 흐리고 원자 저장 방식이 운영체제에 따라 달라지게 했다.

## 정리 내용

- 오디오 카탈로그의 실행 파일 기준 경로 탐색에서 `_WIN32` 조건부 분기를 제거했다.
- 설정, 전투 기록과 진행 중 런 체크포인트의 비-Windows `std::filesystem::rename` 대체 구현을 제거했다.
- 세 저장소의 기본 경로 탐색을 Windows `LOCALAPPDATA` 기준 단일 경로로 정리했다.
- 저장 파일 교체는 Windows `MoveFileExW`의 기존 파일 교체·디스크 반영 옵션만 사용하도록 고정했다.
- `std::filesystem`은 Windows 경로 조합, 파일 검증, 백업·복구와 테스트에 필요하므로 유지했다.
- x86/x64는 모두 Windows 배포·회귀 구성이라 제거하지 않았다.
- 빌드 문서에 Windows 10/11 전용 지원 범위를 명시했다.
