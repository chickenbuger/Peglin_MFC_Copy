## 변경 사항

- `Parent_ball::shooting()`이 발사 성공 여부를 `bool`로 반환한다.
- 드래그 거리가 `0.001f` 이하이면 속도·힘을 0으로 유지하고 발사를 취소한다.
- 마우스 버튼을 누른 기록이 있을 때만 버튼 해제에서 발사를 시도한다.
- 정상 드래그의 방향과 힘 계산은 기존 규칙을 유지한다.

## 검증 기준

- 취소 직후 정상 드래그 발사로 공이 이동함 — 통과
- 한글 체력 문구와 화면 렌더링 유지 — 통과
- Debug/Release × x64/x86 네 구성 재빌드 성공 — 통과

## 결론

0 길이 드래그가 더 이상 NaN 속도를 만들지 않으며 잘못된 버튼 해제 이벤트도 발사를 시작하지 않는다.
