## 개선 이유

설정과 전투 기록은 재실행 후 복구되지만, 여러 스테이지로 이어지는 현재 런은 프로그램을 닫으면 사라졌다. 긴 런을 안전하게 이어갈 수 있도록 화면 전환이 완료된 안정 지점에서만 진행 상태를 저장하고, 손상·버전 불일치 시 사용자 데이터를 보호해야 했다.

## 구현 내용

- `RunCheckpointStore` Version 1 포맷을 추가해 경로 레이어, 현재 노드, 클리어 이력, 선택 경로, 난이도, 체력, 골드, 오브 덱, 선호 오브, 유물과 상점 구매 상태를 저장한다.
- 임시 파일 작성 후 `MoveFileExW(..., MOVEFILE_REPLACE_EXISTING | MOVEFILE_WRITE_THROUGH)`로 교체하는 원자 저장을 적용했다.
- 정상 주 파일을 `.bak`으로 보존하고, 주 파일 손상 시 `.recovery`를 거쳐 마지막 정상 체크포인트를 복구한다.
- 지원하지 않는 신규 저장 버전과 현재 콘텐츠에서 사라진 ID가 포함된 저장 파일은 덮어쓰지 않고 해당 실행의 자동 저장을 비활성화한다.
- 새 런 시작, 보상 선택, 경로 선택·확정, 상점 구매·퇴장, 장비 변경과 전투 승리 뒤 체크포인트를 갱신한다.
- 전투 도중 종료하면 물리 프레임을 직렬화하지 않고 해당 스테이지의 시작 상태로 재개해 타이머·충돌 내부 상태 의존성을 제거했다.
- 최종 보스 클리어 시 완료된 런 체크포인트를 제거한다.
