# Version 1.7 — 피해·턴 전환 피드백

## 버전 정보

| 항목 | 값 |
| --- | --- |
| 버전 | Version 1.7 |
| 스프린트 | Sprint 1 |
| 작업일 | 2026-08-29 (Asia/Seoul) |
| 목적 | 상태와 충돌 결과를 화면에 표시해 발사 결과와 턴 전환 원인을 명확히 전달 |
| 판정 | **완료 — 빌드·자동 테스트·실제 화면 검증 통과** |

## 변경 사항

- `GameFeedbackType`과 `GameFeedback`을 추가해 준비, 발사, 페그 적중, 턴 정산, 플레이어 피해, 승리·패배, 일시정지 결과를 명시적으로 표현한다.
- 한 발에서 제거한 페그 수, 턴 번호, 마지막 몬스터 피해와 플레이어 피해를 `GameWorld`가 보관한다.
- 발사 성공, 페그 충돌, 턴 정산과 일시정지 상태 전환 시 해당 피드백을 같은 게임 모델에서 갱신한다.
- 상단 정보 영역에 현재 게임 상태와 최근 결과 문구를 표시한다.
- 상태·피드백 텍스트 좌표도 `GameLayout`에 포함해 렌더링 상수 분산을 막았다.
- GDI 텍스트 출력은 `SaveDC/RestoreDC` 범위에서 배경 모드와 색상을 설정한다.

## 자동 검증

- 페그 1회 충돌 후 `PegHit` 이벤트와 현재 발사 적중 수 `1`을 확인한다.
- 일반 턴 종료 후 `TurnResolved` 이벤트와 몬스터 피해 `1`을 확인한다.
- 패배 전이 후 `Defeat` 이벤트와 플레이어 피해 `20`을 확인한다.
- Debug/Release × x64/x86 네 테스트 실행 파일이 각각 **53개 검증을 모두 통과**했다.

## 빌드·실행 검증

- Debug/Release × x64/x86 네 구성 빌드 성공: 오류 0개, 자체 코드 경고 0개.
- Debug x64 초기 화면에서 `상태: 조준 중`과 발사 안내 문구를 확인했다.
- `(492,326)→(430,226)` 드래그 후 비행 중 `상태: 공 비행 중`, `이번 발사 적중: 8`을 확인했다.
- 턴 종료 후 `상태: 조준 중`, `턴 1: 몬스터 피해 10`, 몬스터 체력 `20→10`을 확인했다.
- 실행 창은 오류 대화상자 없이 정상 종료됐다.

## 결론

플레이어는 현재 입력 가능 여부와 한 발의 적중 수, 턴 종료 피해 결과를 즉시 확인할 수 있다. 다음 단계에서는 명시적 시드와 데이터 정의를 사용하는 재현 가능한 페그 배치 경로를 만든다.
