## 최종 빌드와 자동화 검증

- Debug/Release × x64/x86 네 구성의 앱과 테스트를 모두 다시 빌드했다.
- 네 구성 모두 오류 0개, 프로젝트 자체 경고 0개다.
- 구성별 `360 PASS / 0 FAIL`, 총 `1,440 PASS / 0 FAIL`이다.
- 설정·기록 Version 0→1 마이그레이션, 손상·중복·오버플로 입력, 단일 승패 결과와 패키지 실패 탐지를 포함한다.

## 실제 플레이와 저장 검증

- 옵션 화면의 난이도·사운드·페그 색상과 자동 저장 안내가 클라이언트 영역 안에 표시됐다.
- 공 위치를 누르고 같은 위치에서 놓았을 때 발사가 취소되고 다음 정상 발사가 가능했다.
- 스테이지 1을 5턴, 점수 8,800, 최고 콤보 10으로 클리어했다.
- 클리어 결과는 한 번만 표시됐고 기록은 `8,800 / 콤보 10 / 클리어 2`로 갱신됐다.
- `R` 재도전은 게임 상태를 초기화하면서 기록을 유지했다.
- 13턴 무득점 패배에서는 플레이어 피해와 게임 오버가 정상 진행됐고 기존 최고 기록·클리어 횟수를 덮어쓰지 않았다.
- `S`로 스테이지 선택 화면에 돌아온 뒤에도 기록이 일치했다.
- 최종 패키지를 종료 후 다시 실행해 보통 난이도·사운드 켜짐·표준 색상과 스테이지별 기록이 그대로 로드됨을 확인했다.

## GDI 안정성

- 30초 워밍업 후 1분 간격으로 10분간 수집한 GDI 객체 수는 `33, 33, 36, 33, 39, 33, 33, 33, 36, 36, 33`이다.
- 마지막 값은 기준값과 같은 33개이며 허용 기준인 기준값 +5 이하를 만족한다.
- 일시적인 화면 전환 표본 이후 다시 기준값으로 내려왔고 후반부 지속 상승이 없다.
- 모든 표본에서 창 응답 상태가 `True`였다.
