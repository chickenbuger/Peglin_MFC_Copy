## 완료 목적

Version 9.1~9.7에서 추가한 진행 중 런 체크포인트, 입력 재매핑, XAudio2 믹싱, XInput 상태·진동, 확장 콘텐츠와 인게임 핫 리로드를 하나의 Windows Release 패키지에서 결합 검증하고 Sprint 9을 종료한다.

## 저장 호환성

- Sprint 8의 설정 Version 3 파일을 읽어 새 키보드·마우스 바인딩 기본값을 충돌 없이 보충하는 이관 경로를 자동 검증했다.
- 설정 Version 0~2와 레거시 기록 Version 0도 현재 형식으로 안전하게 이관되며, 손상된 주 파일은 검증된 백업에서 복구한다.
- 지원하지 않는 미래 버전은 자동으로 덮어쓰지 않고 거부한다.
- Version 9의 진행 중 런 체크포인트는 경로·선택 노드·체력·골드·덱·유물·상점 상태를 보존하며, 손상 복구와 현재 콘텐츠 ID 호환성을 검증한다.
- 핫 리로드는 진행 중인 런의 스테이지와 보유 오브·유물 ID가 모두 남아 있을 때만 새 카탈로그를 적용한다.

## XInput 완료 기준

사용자 결정에 따라 실제 XInput 장비의 손맛·진동 체감·물리 연결 복구 QA는 Sprint 9 완료 조건과 대기 사유에서 제외했다. Version 9.4의 연결·분리·재연결 상태 전이, 오발 방지, 이벤트별 모터 파형, 우선순위, 종료 페이드와 양쪽 모터 0 복귀 자동 회귀 및 Windows 미연결 실행 경로를 최종 기준으로 사용했다.
