## 개선 이유

기존 페그 충돌음은 실행 중 생성한 PCM 한 종류뿐이고 전체 음소거만 제공했다. 장면별 배경음과 전투 사건별 효과음을 확장하기 어렵고, 사용자가 배경음과 효과음을 따로 조절할 수도 없었다. 또한 배포 파일에 음원이 빠져도 사전 검사에서 발견할 방법이 필요했다.

## 구현 내용

- `content/audio.v1.ini`를 추가해 효과음과 음악을 안정 ID, 상대 WAV 경로, 반복 여부로 관리한다.
- 경로 이탈, 중복 ID, 누락 파일, 지원하지 않는 WAV와 과대 파일을 거부하는 오디오 카탈로그 로더를 구현했다.
- 페그 충돌, 폭탄, Refresh, 공격, 피해, 승리, 패배와 UI 확인 효과음 8개를 파일 자산으로 교체했다.
- 모험, 전투, 상점 화면용 반복 BGM 3개를 추가하고 화면 전환에 따라 자동으로 변경한다.
- 효과음은 PCM16 샘플 자체를 조절하고 BGM은 MCI 볼륨을 사용해 서로 독립적으로 0~100% 설정한다.
- 설정 파일을 Version 2로 올리고 Version 0·1 설정은 기존 선택을 보존한 채 새 볼륨 기본값으로 마이그레이션한다.
- 옵션 화면에 효과음·배경음 볼륨 타일과 키보드 단축키 `E`, `V`를 추가하고 마우스 적중 영역을 동기화했다.
- Release 패키지에 카탈로그와 11개 WAV를 포함하고 누락된 카탈로그·개별 음원을 사전 검사에서 실패 처리한다.
- 동일 자산을 재생성할 수 있는 `tools/Generate-AudioAssets.py`를 추가했다.
