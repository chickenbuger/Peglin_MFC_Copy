## 개선 이유

일반 페그 충돌도 Windows 시스템 기본 경고음을 사용해 짧은 플레이에서도 음색이 날카롭게 들렸고, 여러 페그를 빠르게 맞히면 같은 소리가 겹쳐 피로감이 커졌다.

## 구현 결과

- 페그 적중 전용 110ms 모노 16-bit PCM 파형을 런타임에 한 번 생성한다.
- 520Hz와 780Hz를 낮은 음량으로 혼합하고 6ms 어택, 지수 감쇠와 끝단 페이드를 적용해 시작·끝 클릭음을 억제했다.
- 정규화 최대 진폭을 14%로 제한해 기존 시스템 경고음보다 부드러운 타격감을 만든다.
- `PegHit`만 전용 파형을 `PlaySoundW` 비동기 메모리 재생으로 처리한다.
- `SND_NOSTOP`으로 짧은 시간에 여러 적중이 발생할 때 기존 소리를 강제로 끊거나 중첩하지 않는다.
- 음소거 옵션을 그대로 따르며 창 종료 시 진행 중인 효과음을 정지한다.
- 승리·패배·폭탄·크리티컬 등 의미가 다른 기존 알림음은 유지한다.
