# Version 0.8 — 단일 고정 시간 간격 게임 루프

## 버전 정보

| 항목 | 값 |
| --- | --- |
| 버전 | Version 0.8 |
| 스프린트 | Sprint 0 |
| 작업일 | 2026-08-29 (Asia/Seoul) |
| 목적 | 분리된 타이머를 관리되는 단일 고정 스텝 루프로 통합 |
| 판정 | **게임 루프 통합 완료** |

## 변경 사항

- `CChildView`가 `SetTimer`의 반환 ID를 멤버로 보관하고 `OnDestroy`에서 `KillTimer`로 해제한다.
- 충돌과 이동·턴·승패 갱신을 하나의 `UpdateGameStep()` 순서로 통합했다.
- `steady_clock`으로 실제 경과 시간을 누적하고 10ms 고정 스텝으로 게임을 갱신한다.
- 한 번에 누적할 프레임 시간을 100ms로 제한해 창 정지나 디버깅 후 과도한 보정이 발생하지 않게 했다.
- `Parent_ball::update(float deltaSeconds)`와 10ms 기준 스케일을 도입해 기존 물리 감각을 유지했다.

## 검증

- Debug/Release × x64/x86 네 구성 재빌드 성공.
- Debug x64에서 발사 후 공의 이동과 페그 충돌·피해 정산이 정상 동작했다.
- 이동 중 `Space`로 공이 정지하고, 다시 `Space`를 누르면 이동이 재개됨을 확인했다.
- 창을 정상 종료한 뒤 게임 창이 남지 않아 타이머 종료 경로를 확인했다.

## 결론

게임 상태 갱신이 두 개의 독립 타이머 호출 순서에 의존하지 않으며, 지연된 프레임도 제한된 누적 시간 안에서 고정된 10ms 단위로 처리된다.
