## 개선 이유

메뉴와 전투 화면이 즉시 교체되어 장면의 연결감이 약했고, 보상 적용과 플레이어 피해가 정적인 문구만으로 전달됐다. 실제 플레이 영상에서는 여러 공격·이동·피해 문구가 동시에 같은 적 영역에 출력되어 타깃 이름과 체력 정보를 가리는 문제도 확인됐다.

## 구현 내용

- 독립적인 고정 시간축 `UiAnimationTimeline`과 ease-out 진행률을 추가했다.
- 화면이 변경될 때 0.28초 동안 중앙에서 위·아래로 열리는 공개 전환을 적용했다.
- 보상 획득 카드에 0.8초 금색·유형색 펄스 테두리를 추가했다.
- 플레이어 피해 시 0.45초 동안 강도가 감소하는 붉은 화면 경고 프레임을 표시한다.
- 페그 위치 효과는 현 위치를 유지하고, 공격·턴·이동·피해·승패 같은 전역 피드백은 중앙 토스트로 분리했다.
- 전역 토스트는 0.34초 간격으로 순차 표시해 같은 프레임의 다중 몬스터 행동도 서로 겹치지 않는다.
- 화면 전환과 지연 토스트는 기존 승패 전환 게이트의 완료 조건 안에서 갱신된다.
- Windows SDK `UIAnimation.h`와의 이름 충돌을 피하도록 프로젝트 시간축 헤더를 `PeglinUiAnimation.h`로 명명했다.
