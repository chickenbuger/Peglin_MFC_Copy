## P0 — Sprint 7 완료 필수 후보

- [x] 분기형 스테이지 선택과 최종 보스 경로 — Version 7.1
  - 이유: 기존 세 스테이지 고정 순서는 클리어 뒤 선택이 없고 콘텐츠가 짧아 Peglin 스타일의 런 진행과 보스 도달 감각이 부족했다.
- [x] 신규 몬스터 시각 타입과 스테이지별 로스터 확장 — Version 7.2
  - 이유: 안정 ID는 여러 개였지만 실제 실루엣은 3종뿐이라 분기 스테이지의 시각적 반복이 컸다.
- [x] Refresh Peg 발동 후 다음 Refresh Peg 1개 보장 — Version 7.3
  - 이유: 현재 원본 배치를 복원할 뿐 소비한 Refresh Peg 자체는 제외되어 연속적인 보드 갱신 기회가 끊길 수 있다.
- [x] 축소된 페그 맵과 사이드 현재·다음 오브 HUD — Version 7.4
  - 이유: 상단 중앙의 오브 패널이 전투 장면과 적 정보를 가리고, 넓은 페그 필드가 사이드 정보 공간을 제한한다.
- [x] 공격 종료 시 Refresh Peg 최소 1개 보장 — Version 7.5
  - 이유: Refresh가 폭발에 제거되거나 Refresh 없는 배치를 사용하면 이후 보드 갱신 기회가 완전히 사라질 수 있다.
- [x] 스테이지 선택 정보 단순화와 연출 완료 후 화면 전환 — Version 7.6
  - 이유: 선택 카드의 READY·과거 기록은 경로 선택에 불필요하고, 공격 투사체가 도착하기 전에 보상·결과 화면으로 전환되면 전투 마무리가 보이지 않는다.
- [x] 오브·유물 이미지와 정확한 보상 효과·획득 확인 — Version 7.7
  - 이유: 이름과 단순 도형만으로는 보상 종류를 빠르게 구분하기 어렵고, 실제 배율·공격 대상·중첩 결과와 획득 적용 여부를 선택 전에 판단할 수 없었다.
- [ ] 파일 기반 효과음·배경음 카탈로그와 개별 볼륨
  - 이유: 현재 페그 충돌음은 코드 생성 PCM이고 음소거만 제공하여 장면별 음향·배경음 확장이 어렵다.
- [ ] 화면 전환·보상·데미지 UI 애니메이션
  - 이유: 전투 공격 연출은 분리되었지만 메뉴·보상·결과 화면 전환은 즉시 교체라 흐름의 연결감이 부족하다.
- [ ] 게임패드 포커스 탐색과 입력 장치 동등성
  - 이유: 키보드·마우스는 동등하지만 거실·휴대형 PC 환경에서 게임패드로 전체 런을 진행할 수 없다.
- [ ] 스테이지·난이도·오브별 상세 통계와 정렬·필터
  - 이유: 최고 점수·콤보·클리어 횟수는 저장하지만 오브·난이도 조합의 성과를 비교할 수 없다.
- [ ] 세이브 백업·손상 복구·선택형 초기화
  - 이유: 현재 손상된 설정·기록은 안전한 기본값으로 복구하지만 이전 정상 데이터를 복원하거나 부분 초기화할 수 없다.
- [ ] 전체 런·오디오·입력·세이브·GDI 최종 회귀와 배포
  - 이유: 입력 장치와 오디오 자원이 늘어나면 종료 정리, 포커스 복구와 패키지 누락 위험을 재검증해야 한다.
