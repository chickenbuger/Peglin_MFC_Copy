## P0 — Sprint 7 완료 필수 후보

- [x] 분기형 스테이지 선택과 최종 보스 경로 — Version 7.1
  - 이유: 기존 세 스테이지 고정 순서는 클리어 뒤 선택이 없고 콘텐츠가 짧아 Peglin 스타일의 런 진행과 보스 도달 감각이 부족했다.
- [x] 신규 몬스터 시각 타입과 스테이지별 로스터 확장 — Version 7.2
  - 이유: 안정 ID는 여러 개였지만 실제 실루엣은 3종뿐이라 분기 스테이지의 시각적 반복이 컸다.
- [x] Refresh Peg 발동 후 다음 Refresh Peg 1개 보장 — Version 7.3
  - 이유: 현재 원본 배치를 복원할 뿐 소비한 Refresh Peg 자체는 제외되어 연속적인 보드 갱신 기회가 끊길 수 있다.
- [x] 축소된 페그 맵과 사이드 현재·다음 오브 HUD — Version 7.4
  - 이유: 상단 중앙의 오브 패널이 전투 장면과 적 정보를 가리고, 넓은 페그 필드가 사이드 정보 공간을 제한한다.
- [x] 공격 종료 시 Refresh Peg 최소 1개 보장 — Version 7.5
  - 이유: Refresh가 폭발에 제거되거나 Refresh 없는 배치를 사용하면 이후 보드 갱신 기회가 완전히 사라질 수 있다.
- [x] 스테이지 선택 정보 단순화와 연출 완료 후 화면 전환 — Version 7.6
  - 이유: 선택 카드의 READY·과거 기록은 경로 선택에 불필요하고, 공격 투사체가 도착하기 전에 보상·결과 화면으로 전환되면 전투 마무리가 보이지 않는다.
- [x] 오브·유물 이미지와 정확한 보상 효과·획득 확인 — Version 7.7
  - 이유: 이름과 단순 도형만으로는 보상 종류를 빠르게 구분하기 어렵고, 실제 배율·공격 대상·중첩 결과와 획득 적용 여부를 선택 전에 판단할 수 없었다.
- [x] 일부 스테이지의 지속 이동 페그 패턴 — Version 7.8
  - 이유: 모든 스테이지의 페그가 정지해 있으면 배치만 달라질 뿐 조준 타이밍과 공의 경로 판단이 반복된다. 일부 페그가 예측 가능한 궤도로 움직이면 같은 오브와 배치에서도 발사 시점에 따른 선택이 생긴다.
- [x] 시작 전 스테이지 재선택과 명시적 경로 확정 — Version 7.9
  - 이유: 별도의 시작 단계가 있는데도 카드 클릭 즉시 다른 선택지가 사라져 실수로 고른 경로를 시작 전에 바꿀 수 없었다. 카드 선택과 실제 경로 확정을 분리해 선택권을 보존해야 한다.
- [x] 골드 기반 Goblin Market 상점 노드와 구매 화면 — Version 7.10
  - 이유: 분기 런이 전투와 보상 선택만 반복되어 전투 사이에 자원을 아끼거나 즉시 전력을 보강하는 선택이 없었다. 전투 보상 골드와 별도 상점 노드를 연결해 오브·유물·회복을 가격과 현재 상태를 비교해 구매할 수 있어야 한다.
- [x] 몬스터 칸 거리와 개별 공격 사거리 — Version 7.11
  - 이유: 다중 몬스터가 표시되어도 선택된 한 마리만 움직이고 공격해 전선의 압박이 없었으며, 근거리·원거리 몬스터의 위협 시점을 구분할 수 없었다. 모든 생존 몬스터가 턴마다 접근하고 개별 사거리 안에서 멈춰 공격해야 거리 판단이 실제 전투 선택으로 이어진다.
- [x] 매 턴 Refresh Peg 위치 변경과 파괴 후 재배치 — Version 7.12
  - 이유: Refresh Peg가 같은 위치에 고정되고 발동 후 원래 자리로 복원되면 매 턴 조준 경로가 반복된다. 턴마다 다른 활성 페그로 이동하고 직접 충돌이나 폭발로 제거될 때도 이전 위치가 아닌 곳에 즉시 재생성되어야 보드 탐색과 경로 선택이 계속 달라진다.
- [x] 일러스트 기반 스테이지 선택 카드와 런 경로 UI — Version 7.13
  - 이유: 기존 선택 화면은 이름 중심의 세로 카드와 별도 규칙 패널로 공간을 사용해 분기 경로의 분위기와 전체 진행 위치를 비교하기 어려웠다. 스테이지별 이미지를 직접 비교하고 현재 런 노드를 한눈에 확인할 수 있어야 선택 과정도 실제 모험의 일부처럼 느껴진다.
- [x] Steam Peglin 참고 UI 계층과 전체 화면 배치 최적화 — Version 7.14
  - 이유: 화면별 기능은 갖춰졌지만 전투 상단의 중복 상태 문구, 메뉴마다 다른 제목 위치와 카드 간격 때문에 플레이 영역과 선택 정보의 우선순위가 흔들렸다. 원작의 큰 플레이필드·고정 장비 정보·간결한 고빈도 상태 표시 원칙을 현재 동굴 UI에 맞게 재해석해 모든 화면의 시선 흐름을 통일해야 했다.
- [x] 파일 기반 효과음·배경음 카탈로그와 개별 볼륨 — Version 7.15
  - 이유: 현재 페그 충돌음은 코드 생성 PCM이고 음소거만 제공하여 장면별 음향·배경음 확장이 어렵다.
- [x] 화면 전환·보상·데미지 UI 애니메이션 — Version 7.16
  - 이유: 전투 공격 연출은 분리되었지만 메뉴·보상·결과 화면 전환은 즉시 교체라 흐름의 연결감이 부족하다.
- [x] 게임패드 포커스 탐색과 입력 장치 동등성 — Version 7.17
  - 이유: 키보드·마우스는 동등하지만 거실·휴대형 PC 환경에서 게임패드로 전체 런을 진행할 수 없다.
- [x] 스테이지·난이도·오브별 상세 통계와 정렬·필터 — Version 7.18
  - 이유: 최고 점수·콤보·클리어 횟수는 저장하지만 오브·난이도 조합의 성과를 비교할 수 없다.
- [ ] 세이브 백업·손상 복구·선택형 초기화 — Version 7.19 예정
  - 이유: 현재 손상된 설정·기록은 안전한 기본값으로 복구하지만 이전 정상 데이터를 복원하거나 부분 초기화할 수 없다.
- [ ] 전체 런·오디오·입력·세이브·GDI 최종 회귀와 배포
  - 이유: 입력 장치와 오디오 자원이 늘어나면 종료 정리, 포커스 복구와 패키지 누락 위험을 재검증해야 한다.
