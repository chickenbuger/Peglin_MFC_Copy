## P0 — Sprint 7 완료 필수 후보

- [ ] 파일 기반 효과음·배경음 카탈로그와 개별 볼륨
  - 이유: 현재 페그 충돌음은 코드 생성 PCM이고 음소거만 제공하여 장면별 음향·배경음 확장이 어렵다.
- [ ] 화면 전환·보상·데미지 UI 애니메이션
  - 이유: 전투 공격 연출은 분리되었지만 메뉴·보상·결과 화면 전환은 즉시 교체라 흐름의 연결감이 부족하다.
- [ ] 게임패드 포커스 탐색과 입력 장치 동등성
  - 이유: 키보드·마우스는 동등하지만 거실·휴대형 PC 환경에서 게임패드로 전체 런을 진행할 수 없다.
- [ ] 스테이지·난이도·오브별 상세 통계와 정렬·필터
  - 이유: 최고 점수·콤보·클리어 횟수는 저장하지만 오브·난이도 조합의 성과를 비교할 수 없다.
- [ ] 세이브 백업·손상 복구·선택형 초기화
  - 이유: 현재 손상된 설정·기록은 안전한 기본값으로 복구하지만 이전 정상 데이터를 복원하거나 부분 초기화할 수 없다.
- [ ] 전체 런·오디오·입력·세이브·GDI 최종 회귀와 배포
  - 이유: 입력 장치와 오디오 자원이 늘어나면 종료 정리, 포커스 복구와 패키지 누락 위험을 재검증해야 한다.

## 진행 규칙

1. 사용자가 Sprint 7 시작을 명시하기 전에는 Version 7.1 구현을 진행하지 않는다.
2. 기능 하나당 `구현 → 네 구성 빌드·테스트 → 실행 검증 → Version 문서 → 커밋·푸시 → Notion`을 유지한다.
3. P0와 검증 게이트를 모두 완료한 뒤에만 Sprint 8 계획을 작성한다.
