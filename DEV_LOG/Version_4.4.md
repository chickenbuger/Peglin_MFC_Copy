## 저장 데이터 마이그레이션

- 설정 Version 0의 숫자 난이도, 문자열 사운드와 숫자 색상 모드를 현재 `GameOptions`로 변환한다.
- 기록 Version 0의 난이도 없는 레코드는 보통 난이도 기록으로 변환한다.
- 로드 결과에 `Migrated` 상태를 추가해 일반 로드와 형식 전환을 구분한다.
- 앱 시작 중 마이그레이션이 성공하면 같은 값을 Version 1 형식으로 즉시 다시 저장한다.
- 잘못된 레거시 값은 마이그레이션하지 않고 기존의 안전한 기본값 복구 정책을 유지한다.

## 패키지 자동 검증

- `tools/Test-ReleasePackage.ps1`이 ZIP 항목의 루트 경로와 `..` 경로 탈출을 검사한다.
- GUID 기반 시스템 임시 하위 폴더에 ZIP을 추출하고 작업 경로가 임시 루트 내부인지 확인한다.
- `PACKAGE_VERSION.txt`와 예상 버전을 비교하고 추출 패키지의 `Preflight.ps1`을 실행한다.
- 정상 패키지 통과 후 별도 복사본의 `README.txt`를 변조해 SHA-256 불일치를 탐지한다.
- 또 다른 복사본에서 `mfc140u.dll`을 제거해 필수 런타임 누락을 탐지한다.
- 검증 성공·실패와 관계없이 확인된 임시 테스트 폴더만 정리한다.
- `Package-Release.ps1`이 ZIP 생성 직후 이 검증을 자동 실행하도록 연결했다.
