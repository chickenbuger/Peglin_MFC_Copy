# Version 1.3 — 2D 벡터 값 타입 도입

## 버전 정보

| 항목 | 값 |
| --- | --- |
| 버전 | Version 1.3 |
| 스프린트 | Sprint 1 |
| 작업일 | 2026-08-29 (Asia/Seoul) |
| 목적 | raw 좌표 배열과 축별 속도 API를 타입 안전한 2D 벡터 값으로 교체 |
| 판정 | **완료 — raw 포인터 좌표 제거 및 빌드·실행 회귀 통과** |

## 변경 사항

- `Vector2`에 덧셈, 뺄셈, 스칼라 곱·나눗셈, 길이, 정규화와 내적 연산을 정의했다.
- 공의 위치, 속도, 조준 시작·추적·종료 좌표를 `Vector2` 값으로 교체했다.
- `GetPos()` raw 포인터와 `Get/SetVelocityX/Y()` 축별 API를 제거하고 `GetPosition()`, `GetVelocity()`, `SetVelocity()`로 교체했다.
- 페그의 공개 `x`, `y` 좌표를 `Vector2 position`으로 통합했다.
- `GameWorld`의 조준 입력과 충돌 계산을 `Vector2` 차이, 길이 제곱, 내적과 스칼라 연산으로 표현했다.
- GDI에 좌표를 전달하는 경계에서는 기존 `std::lround` 정수 변환을 유지했다.

## 검증

- `GetPos()`, raw 위치 배열, 축별 속도 getter/setter와 이전 `_velocity_x/y` 참조가 전체 소스에서 0개임을 확인했다.
- 레거시 `Parent_ball.h/.cpp`는 변경 후에도 CP949 선두 바이트와 한글 주석을 보존했다.
- Debug/Release × x64/x86 네 구성 `/W4` 재빌드 성공: 오류 0개, 자체 코드 경고 0개.
- Debug x64 실제 창에서 페그 48개 렌더링, 동일 드래그 발사, 페그 1개 제거, 적 체력 `20→19`, 공과 턴 초기화가 기존과 일치함을 확인했다.
- 오류 대화상자 없이 정상 종료했다.

## 결론

좌표와 속도의 의미가 배열 인덱스나 서로 분리된 축 API에 의존하지 않게 됐다. 다음 단계에서는 이 벡터 연산을 사용해 페그 충돌을 법선 반사와 반발계수 기반으로 개선한다.
