## 결합 회귀

- 배포된 외부 `stage-3` 보스 정의에 Echo Orb, Combo Lantern, Thorn Charm과 Bark Guard를 함께 적용했다.
- 효과 순서를 오브 → 유물 획득 순서로 유지해 최종 배율을 피해 0.96, 점수 1.875, 받는 피해 0.85로 확인했다.
- Critical 적중 결과가 피해 1.92, 점수 375로 계산되고 외부 보스 스테이지에서 Victory와 결과 요약으로 이어졌다.
- 승리 결과가 한 번만 보고되고 재도전 시 보스 체력 60, 행동 인덱스 0, 방어막 0으로 복원되며 장비는 유지됐다.
- 같은 조합에서 보스 행동 패턴이 15턴에 플레이어를 결정적으로 Defeat 상태로 만들고 결과가 한 번만 보고됐다.
- 패배 재도전은 플레이어 체력 110과 장비를 복원하고, 명시적 진행 초기화만 기본 오브·유물 없음으로 되돌렸다.

## 최종 빌드·자동 테스트

- Debug/Release × x64/x86 앱·테스트 최종 빌드 성공.
- 네 구성 모두 오류 0개, 프로젝트 자체 경고 0개.

- Version 4 설정·기록 Version 0→1 마이그레이션과 손상·중복·오버플로 안전 실패 회귀가 계속 통과했다.
- 외부 콘텐츠의 누락·손상·버전·UTF-8·크기·중복·범위·부분 정의 실패와 내장 복구를 모두 검증했다.

## 실제 실행·UI

- Debug x64에서 ImageGen 배경, 스테이지·장비·옵션 화면과 게임 HUD를 직접 확인했다.
- 방향키 선택, Enter 시작, Iron Orb·Combo Lantern 선택·유지와 Dense Cavern 시작을 확인했다.
- 실제 클라이언트 영역 기준으로 수정한 하단 키 안내가 스테이지·장비·옵션에서 모두 표시됐다.
- Release x64를 GDI 측정 동안 10분 이상 실제 렌더링하고 모든 표본에서 응답 상태를 유지했다.
- 측정과 패키지 스모크 실행 종료 뒤 잔류 게임 프로세스와 마우스 캡처가 없었다.

## GDI 안정성

- 30초 워밍업 후 0~10분, 1분 간격 표본: `32, 32, 34, 37, 35, 32, 35, 37, 32, 32, 35`
- 기준 32, 마지막 35, 기준 대비 +3으로 허용 +5 이하다.
- 후반 표본 `35, 37, 32, 32, 35`는 지속 상승하지 않았고 전 표본 `Responding=True`였다.
- 판정: **GDI 안정성 게이트 통과**.
