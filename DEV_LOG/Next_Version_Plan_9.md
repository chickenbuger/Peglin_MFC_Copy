## P0 — Sprint 9 후보

- [x] 진행 중인 런 저장·재개와 원자적 체크포인트 — Version 9.1
  - 이유: 현재 설정·기록은 복구되지만 여러 스테이지를 진행하던 런은 프로그램 종료 후 이어갈 수 없다.
- [ ] 키보드·마우스·게임패드 키 바인딩 편집과 충돌 검사
  - 이유: 게임패드 발사 버튼 외의 입력은 고정되어 사용자별 접근성 요구를 충분히 반영하지 못한다.
- [ ] XAudio2 기반 다중 효과음 보이스와 카테고리별 덕킹
  - 이유: 현재 WinMM 단일 효과음 채널은 폭주를 안전하게 제한하지만 서로 다른 효과음을 자연스럽게 겹쳐 재생하지 못한다.
- [ ] 실제 XInput 장비 손맛·진동·연결 복구 QA
  - 이유: Sprint 8 환경에는 물리 패드가 없어 입력 수학과 미연결 안전 경로만 검증했다.
- [ ] 스테이지·몬스터·오브·유물 추가와 난이도 곡선 자동 분석
  - 이유: 현재 전체 런은 완결되지만 반복 플레이의 빌드 조합과 조우 다양성을 더 늘릴 여지가 있다.
- [ ] 콘텐츠 제작자용 인게임 미리보기·핫 리로드
  - 이유: Markdown 리포트는 실행 전 검증에 유용하지만 배치 수정 결과를 게임 안에서 바로 반복 확인할 수 없다.
- [ ] Sprint 9 결합 회귀·저장 호환성·최종 배포
  - 이유: 저장 포맷, 입력, 오디오와 외부 콘텐츠 변경을 기존 Version 8 데이터 및 배포 패키지와 함께 검증해야 한다.

## 진행 규칙

1. 사용자가 Sprint 9 시작을 명시한 뒤 Version 9.1부터 순서대로 진행한다.
2. 기능 하나당 `구현 → 네 구성 빌드·테스트 → 실행 검증 → Version 문서 → 커밋·푸시 → Notion`을 유지한다.
3. Sprint 종료 시 계획 전체 목록과 각 항목의 완료 여부를 반드시 표출한다.
4. 후보 우선순위와 범위는 Sprint 9 시작 시 다시 확인하며, 시작 전에는 기능을 구현하지 않는다.
