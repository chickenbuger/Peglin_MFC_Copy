# Version 0.4 — Visual Studio 생성물 추적 정리

## 버전 정보

| 항목 | 값 |
| --- | --- |
| 버전 | Version 0.4 |
| 스프린트 | Sprint 0 |
| 작업일 | 2026-08-29 (Asia/Seoul) |
| 목적 | 소스 변경과 빌드 산출물을 분리해 기능별 Git 이력을 안정적으로 관리 |
| 판정 | **저장소 기준선 정리 완료** |

## 변경 사항

- `.vs/`, Debug/Release, x64 빌드 출력 디렉터리를 `.gitignore`에 추가했다.
- PDB, IDB, ILK, TLOG, recipe, lastbuildstate, APS, user 및 리소스 중간 파일을 제외했다.
- 이미 Git에 추적되던 생성물은 인덱스에서만 제거했다. 로컬 파일은 삭제하지 않았다.
- 소스, 리소스 원본, 프로젝트 설정과 개발 기록은 계속 추적한다.

## 검증 기준

- Debug/Release × x64/x86 네 구성 재빌드 성공
- 빌드 후 생성물 변경이 `git status`에 다시 나타나지 않음
- Version 0.4 커밋에는 `.gitignore`, 생성물의 인덱스 제거 및 개발 기록만 포함

## 결론

이후 기능별 커밋은 실제 소스·설정·문서 변경만 포함할 수 있다. 빌드 산출물은 로컬에 남아 개발과 실행에 사용할 수 있지만 GitHub 변경 이력에는 포함되지 않는다. 저장소 기준선 정리 항목 세 가지를 모두 통과했다.
