## 구현 이유

- 점수, 네 종류 페그 효과와 스테이지 규칙은 각각 정상 동작해도 조합 순서에 따라 중복 보상, 연쇄 효과와 승패 반복 문제가 생길 수 있다.
- P0 구현 완료 시점에 실패 경로와 조합 규칙을 자동화해 최종 수동 플레이와 장시간 안정성 검증의 범위를 명확히 해야 한다.

## 추가한 회귀 범위

### 점수·입력

- 적중 후 `F5`가 현재 발사 점수와 콤보를 버리고 총점은 확정하지 않는지 확인
- `F5` 후 새 발사가 콤보 1, 점수 100부터 다시 시작하는지 확인
- 이미 달성한 최고 콤보는 유지되는지 확인

### 페그 효과 조합

- 첫 폭탄이 근처 폭탄을 제거해도 두 번째 폭탄의 범위 효과가 연쇄 실행되지 않는지 확인
- 폭탄 범위 밖 페그, 적중 수와 콤보 점수가 결정적으로 유지되는지 확인
- 두 Refresh를 순서대로 적중해도 활성 페그가 중복 생성되지 않는지 확인
- 새로고침 반복 후 원래 정의당 페그가 하나씩만 존재하는지 확인

### 스테이지 오류 행렬

- 256개 초과 페그, 알 수 없는 페그 열거값, 유효하지 않은 플레이어 체력·공격 피해·적 이동 거리 거부
- `stage-2` 반복 로딩 시 모든 위치와 종류가 같은지 확인

### 승패 회귀

- 스테이지 Critical 피해로 Victory 전이 확인
- 스테이지 공격 피해로 Defeat 전이 확인
- 두 종료 결과가 각각 한 번만 반환되는 Version 1.10 회귀 확인
