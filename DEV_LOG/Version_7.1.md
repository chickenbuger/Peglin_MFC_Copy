## 개선 목적

기존 런은 세 스테이지를 정해진 순서로만 진행해 클리어 뒤의 선택과 장기 진행 감각이 부족했다. 스테이지를 클리어할 때마다 다음 두 경로 중 하나를 고르고, 선택한 경로만 기록한 뒤 마지막 보스에 도달하는 구조로 바꿨다.

## 구현 내용

- 런 상태에 `StageChoice`를 추가해 `전투 완료 → 보상 → 다음 경로 선택 → 전투 준비` 순서를 명시했다.
- 스테이지 카탈로그를 고정 시작 1개, 선택 전투 3계층, 최종 보스 1개로 구성하는 분기 경로 빌더를 추가했다.
- 경로마다 최대 두 개의 카드만 표시하고 마우스 클릭 또는 숫자 `1/2`로 다음 노드를 고를 수 있게 했다.
- 선택하지 않은 스테이지는 클리어 기록에 포함하지 않으며, 마지막 계층은 보스 하나만 허용한다.
- 기존 3개 스테이지에 일반 스테이지 5개를 더해 총 8개 콘텐츠를 제공한다.
  - `Thornwood Thicket`
  - `Fungal Hollow`
  - `Crystal Grotto`
  - `Ember Roost`
  - `Shaman Mire`
- 새 스테이지마다 서로 다른 페그 수·배치·특수 페그·적 3마리·체력·공격 주기를 적용했다.
- 외부 카탈로그가 없거나 손상되어도 동일한 8개 내장 스테이지와 분기 규칙으로 복구되게 했다.
- 빈 경로, 중복 ID, 보스 누락·중복, 과도한 선택지와 잘못된 선택 인덱스를 거부한다.

## 실제 실행 검증

1. 첫 노드 `Forgotten Forest`를 시작해 전투와 페그 충돌을 확인했다.
2. 적을 처치하자 스테이지 보상이 한 번 표시되는 것을 확인했다.
3. 보상 선택 뒤 다음 경로 카드 두 장과 진행도 `2/5`가 표시되는 것을 확인했다.
4. 두 번째 경로 `Fungal Hollow`를 선택하고 고유 45페그 배치와 3마리 적 전투가 로드되는 것을 확인했다.
5. 실행 종료 뒤 게임 프로세스와 입력 캡처가 남지 않는 것을 확인했다.
