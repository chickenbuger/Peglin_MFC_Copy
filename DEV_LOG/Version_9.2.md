## 개선 이유

게임패드 발사 버튼 외에는 플레이 입력이 코드에 고정되어 있었다. 키 배치 선호나 마우스 사용 습관이 다른 사용자가 핵심 전투 동작을 바꿀 수 없었고, 단순 저장만 추가하면 두 동작이 같은 키를 사용하는 충돌 상태가 만들어질 수 있었다.

## 구현 내용

- 옵션 화면에 키보드 일시정지, 전투 로그, 마우스 조준과 기존 게임패드 발사 바인딩을 함께 배치했다.
- 키보드 후보는 `SPACE`, `P`, `H`, `C`, 마우스 조준은 왼쪽/오른쪽 버튼, 게임패드 발사는 A/오른쪽 트리거로 편집할 수 있다.
- 동일 키보드 키를 일시정지와 전투 로그에 중복 배정하는 요청은 원본 값을 유지한 채 거부한다.
- 순환 편집 중 충돌 후보를 만나면 다음 안전 키로 이동하고 충돌을 건너뛰었다는 안내를 표시한다.
- 마우스 오른쪽 버튼 조준을 MFC 메시지 맵과 Capture/Release 안전 처리에 연결했다. 메뉴 조작은 항상 왼쪽 클릭으로 유지한다.
- `GameSettingsStore`를 Version 4로 올려 입력 바인딩을 원자 저장하며, Version 3 설정은 충돌 없는 기본 바인딩으로 자동 이관한다.
- 충돌하거나 알 수 없는 바인딩을 포함한 설정은 디스크에 기록하지 않는다.
- 옵션의 마우스 클릭 영역과 게임패드 포커스를 12개 타일 전체에 맞게 확장했다.
