## 개선 이유

외부 INI는 실행 시 안전하게 검증됐지만 제작자가 변경 결과를 확인하려면 게임을 켜고 여러 스테이지를 직접 찾아가야 했다. 특히 전체 페그·이동 페그·Refresh 분포, 적 참조와 오브·유물의 최종 합성 배율을 한 번에 비교할 도구가 없었다.

## 구현 내용

- 게임과 동일한 C++ `ContentCatalog`·`GameplayCatalog` 로더를 사용하는 결정적 Markdown 리포트 생성기를 추가했다.
- 스키마, UTF-8, 좌표·범위, 효과 그래프와 모든 적 참조가 통과해야만 리포트를 생성한다.
- 전체 스테이지·페그·이동·Refresh·적·오브·유물 수와 스테이지별 페그·적 체력·공격력·설계 비교 지표를 표로 제공한다.
- 적 안정 ID의 최종 피해 배율·사거리와 오브·유물의 합성된 정확한 효과를 미리보기 표로 제공한다.
- `tools/Write-ContentReport.ps1`에서 출력 경로 이탈을 차단하고 선택한 Debug/Release·x64/x86 검증 실행 파일로 리포트를 재생성할 수 있다.
- 현재 카탈로그의 생성 결과를 `Content_Report_8.3.md`에 함께 기록했다.

## 실행 방법

```powershell
& '.\tools\Write-ContentReport.ps1' -Configuration Release -Platform x64
```
