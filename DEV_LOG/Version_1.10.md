# Version 1.10 — 게임 종료 메시지 단일 표시

## 버전 정보

| 항목 | 값 |
| --- | --- |
| 버전 | Version 1.10 |
| 스프린트 | Sprint 1 유지보수 |
| 날짜 | 2026-08-29 |
| 상태 | 구현 및 검증 완료 |

## 문제 분석

- `GameWorld::Update()`는 `Victory` 또는 `Defeat` 상태에 머무는 동안 매 게임 스텝마다 같은 종료 결과를 반환했다.
- `AfxMessageBox()`가 표시한 모달 메시지 루프에서도 10ms 게임 타이머가 계속 처리됐다.
- 첫 번째 메시지 박스를 닫기 전에 타이머가 게임 종료 결과를 다시 받아 동일한 메시지 박스를 중첩 생성할 수 있었다.

## 변경 사항

- 종료 결과가 한 번 보고됐는지 추적하는 `_terminalResultReported` 상태를 `GameWorld`에 추가했다.
- 승리와 패배 상태는 첫 번째 업데이트에서만 각각 `Victory`, `Defeat`를 반환하고 이후 업데이트에서는 `None`을 반환한다.
- 새 게임과 공 초기화 시 종료 결과 보고 상태도 함께 초기화한다.
- 승리와 패배 결과가 반복되지 않는 회귀 테스트 4개를 추가했다.
- 동일한 원인을 공유하는 `Game Clear!!`와 `Game Over!!` 메시지 모두 단일 표시 규칙의 적용을 받는다.

- `Game Clear!!` 대화상자가 3초 이상 한 개만 유지되는 것을 확인했다.
- 확인 버튼을 한 번 눌렀을 때 추가 대화상자가 나타나지 않고 플레이어 체력 100, 몬스터 체력 20, 공과 페그가 새 게임 상태로 복원됐다.
- 검증 종료 후 게임 프로세스가 남지 않는 것을 확인했다.
