# Version 0.13 — 미사용 프로토타입 상태 제거

## 버전 정보

| 항목 | 값 |
| --- | --- |
| 버전 | Version 0.13 |
| 스프린트 | Sprint 0 |
| 작업일 | 2026-08-29 (Asia/Seoul) |
| 목적 | 실행 경로와 무관한 실험 코드·상태·API 제거 |
| 판정 | **미사용 코드 정리 완료** |

## 변경 사항

- 저장소 전체 참조 검색에서 프로젝트 등록 외 사용이 없던 `ball_liner.cpp/.h`를 삭제했다.
- Visual Studio 프로젝트와 필터에서 두 파일 등록을 제거했다.
- `Parent_ball`의 미사용 `_mass`, 페그 충돌 플래그와 관련 getter/setter를 제거했다.
- 외부 호출이 없는 공 위치·크기·힘 및 드래그 배열 getter/setter를 제거했다.
- `Enemy`의 미사용 `damage`, `SetDamage()`, `GetInit()`을 제거했다.

## 검증

- 삭제한 클래스·상태·API 이름에 대한 소스·프로젝트 참조가 0개임을 확인했다.
- Debug/Release × x64/x86 네 구성 재빌드 성공.
- 구성별 기존 경고가 50개에서 44개로 감소했다. 남은 자체 경고는 Version 0.14에서 처리한다.
- Debug x64에서 초기 화면과 48개 페그가 표시되고 정상 드래그 발사·공 이동·종료가 동작했다.

## 결론

실제 게임 실행 경로와 실험용 궤적 프로토타입의 경계가 명확해졌고, 이후 `/W4` 경고 정리 대상에서 사용하지 않는 구현이 제거됐다.
