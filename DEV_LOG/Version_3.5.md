## 최종 빌드·자동화 테스트

- Windows SDK `10.0.26100.0`, MSVC v143, C++20, `/W4` 기준을 유지했다.
- Debug/Release × x64/x86 네 구성에서 앱과 `PeglinCoreTests`를 최종 빌드했다.
- 네 구성 모두 오류 0개, 프로젝트 자체 경고 0개다.
- 각 테스트 실행 파일이 272개 검증을 통과해 총 `1,088 PASS / 0 FAIL`을 기록했다.
- 마지막 빌드와 테스트 직후 빌드 생성물이 Git 변경 목록에 나타나지 않았다.

## 실제 입력·플레이 회귀

- Release x64에서 앱 시작 시 기본 설정과 `stage-1`·`stage-2` 선택 정보가 표시됐다.
- 옵션 화면에서 어려움, 사운드 끄기와 고대비 모드를 선택했으며 `stage-1`은 적 체력 30·6회 이동, `stage-2`는 적 체력 45·4회 이동으로 적용됐다.
- 고대비 페그 표식, 조준 점선, 0~100 발사 세기와 실제 발사 방향을 확인했다.
- 같은 위치 클릭·해제는 발사를 취소했고 이후 정상 발사와 F5 조준 복귀가 가능했다.
- 특수 페그 적중 시 점수·콤보·폭탄·새로고침 애니메이션이 표시됐고 사운드 켜기·끄기가 즉시 반영됐다.
- `stage-1` 클리어 결과는 점수 8,800, 최고 콤보 10, 5턴으로 한 번만 표시됐다.
- 클리어 화면을 2초 이상 유지해도 중복 메시지나 결과 전이가 발생하지 않았고 `[R]`로 같은 스테이지를 새 상태로 재시작했다.
- 페그를 피하는 발사를 반복해 13턴에 플레이어 체력이 0이 되자 점수 0, 최고 콤보 0인 게임 오버 화면이 한 번만 표시됐다.
- 게임 오버 화면을 2초 이상 유지해도 중복 표시가 없었고 `[S]`로 스테이지 선택 화면에 복귀했다.
- 전체 과정에서 ASSERT, 예외, 접근 위반과 잔류 마우스 캡처가 없었으며 게임 창을 정상 종료했다.

## GDI 10분 안정성

- Release x64를 30초 워밍업한 뒤 실제 발사·승리·패배·재시작을 수행하며 1분 간격으로 0~10분 표본을 측정했다.
- GDI 객체 표본: `31, 31, 37, 35, 31, 31, 37, 38, 36, 37, 31`
- 마지막 값은 기준과 동일해 증가 0개로 허용치 +5 이하다.
- 일시적인 변동은 있었지만 후반 표본이 단조 증가하지 않았고 마지막에 기준값으로 복귀했다.
- 모든 표본에서 프로세스 `Responding=True`였다.
