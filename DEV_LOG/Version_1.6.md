# Version 1.6 — 통합 게임 레이아웃 설정

## 버전 정보

| 항목 | 값 |
| --- | --- |
| 버전 | Version 1.6 |
| 스프린트 | Sprint 1 |
| 작업일 | 2026-08-29 (Asia/Seoul) |
| 목적 | 보드·벽·공·페그·캐릭터 좌표와 크기를 단일 레이아웃 설정으로 통합 |
| 판정 | **완료 — 하드코딩 좌표 통합 및 빌드·테스트·화면 검증 통과** |

## 변경 사항

- `GameLayout`에 창과 장면 크기, 보드 경계, 공 초기 위치·반경과 충돌 경계를 정의했다.
- 페그 열·행, 시작 좌표, 간격과 반경을 같은 설정에 통합했다.
- 플레이어·적 위치와 크기, 체력 텍스트 위치, 적 이동 간격과 공격 전환 횟수를 통합했다.
- `Background`, `Parent_ball`, `TargetBall`, `Player`, `Enemy`, `GameWorld`, `CChildView`, `CMainFrame`이 동일한 설정을 사용하도록 변경했다.
- 조준 궤적 미리보기와 실제 벽 충돌이 같은 공 중심 경계를 사용하도록 맞췄다.

## 검증

- 기존 공·적·페그·벽 좌표 상수 검색 결과가 `GameLayout.h` 외부에서 0개임을 확인했다.
- 레이아웃이 공 초기 위치, 적 초기 위치, 페그 12×4 개수와 첫 페그 좌표를 제어하는 자동 검증 5개를 추가했다.
- Debug/Release × x64/x86 네 구성에서 앱과 테스트 프로젝트가 오류 0개, 자체 코드 경고 0개로 빌드됐다.
- 네 테스트 실행 파일이 각각 47개 검증을 모두 통과했다.
- Debug x64 실제 창에서 기존 크기, 배경, 플레이어·적, 체력 텍스트, 공과 화면 내부 페그 48개가 같은 위치에 표시됨을 확인했다.

## 결론

해상도나 보드 구성을 바꿀 때 물리와 렌더링의 여러 파일을 따로 수정할 필요가 없어졌다. 다음 단계에서는 상태와 충돌 이벤트를 이용해 피해·턴 전환을 화면에 명확히 표시한다.
