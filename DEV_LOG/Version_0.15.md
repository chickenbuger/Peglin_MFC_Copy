## 빌드 검증

- Windows SDK `10.0.26100.0`, MSVC v143, C++20, `/W4` 조건으로 네 구성을 다시 빌드했다.
- Debug/Release × x64/x86 모두 오류 0개, 자체 코드 경고 0개로 성공했다.
- 네 구성 모두 문서화된 위치에 실행 파일이 생성됐다.
- 빌드 전후 `git status`가 깨끗해 Visual Studio 생성물이 다시 추적되지 않음을 확인했다.

## 입력·초기화 검증

- 같은 위치에서 클릭·해제한 경우 공이 움직이지 않았고, 이어지는 정상 드래그 발사는 성공했다.
- `F5`와 `새 게임`을 반복해 공의 위치·속도·입력 상태가 매번 같은 초기값으로 돌아오는 것을 확인했다.
- 창 제목 표시줄까지 드래그한 뒤 놓아도 버튼 해제 입력이 처리됐다.
- `Alt+Tab` 포커스 전환과 종료 이후 마우스 Capture 및 커서 제한이 남지 않았다.
- `Space` 일시정지 동안 공 위치가 유지되고, 재개 뒤 게임 루프가 정상 진행됐다.

## 플레이 흐름 검증

- 동일한 드래그에서 Debug와 Release x64 모두 같은 페그 1개를 제거하고 적 체력이 `20→19`로 감소했다.
- 반복 발사로 공이 화면 아래로 나갈 때 턴이 넘어가고 적 이동과 플레이어 피해가 정상 처리됐다.
- 플레이어 체력이 `100→80→60→40→20→0`으로 감소한 뒤 `Game Over!!`가 표시됐고, 확인 후 체력 100·적 체력 20·페그 48개의 새 게임 상태로 복귀했다.
- 다른 열을 겨냥한 반복 발사로 적 체력을 0까지 낮췄을 때 `Game Clear!!`가 표시됐고, 확인 후 동일한 새 게임 상태로 복귀했다.
- 좌·우 벽과 천장 접촉을 포함한 반복 플레이에서 비정상 진동, ASSERT, 예외 또는 접근 위반을 발견하지 못했다.

## GDI 장기 안정성 검증

- Debug x64 실행 후 30초 워밍업을 거쳐 10분 동안 1분 간격으로 프로세스 GDI 객체 수를 측정했다.
- 표본: `31, 31, 31, 31, 37, 34, 38, 39, 39, 36, 34`
- 기준값 31개에서 마지막 값 34개로 증가는 3개이며 허용 기준인 5개 이하를 만족했다.
- 후반 5개 표본은 `38, 39, 39, 36, 34`로 지속 상승하지 않았고 모든 표본에서 프로세스가 응답했다.
