## 개선 이유

스테이지와 적 로스터의 일부 정보는 외부 파일에서 읽었지만 오브·유물 수치와 적별 피해 속성은 C++ 상수에 남아 있었다. 새 콘텐츠를 추가하거나 밸런스를 조정할 때 재컴파일이 필요했고, 서로 참조하는 효과의 오류를 적용 전에 검출할 방법도 없었다.

## 구현 결과

- `content/gameplay.v1.ini`에 재사용 효과, 오브, 유물과 적별 효과 연결을 분리했다.
- 오브·유물 정의를 소유 문자열 기반 런타임 카탈로그로 변경하고 검증된 외부 카탈로그를 원자적으로 활성화한다.
- `PegDamageMultiplier`, `ScoreMultiplier`, `IncomingDamageMultiplier`, `EnemyDamageTakenMultiplier` 네 효과 종류를 지원한다.
- 효과의 `include` 참조를 재귀적으로 합성하며 안정 ID 기반 교차 참조를 사용한다.
- 적 효과는 스테이지 로스터의 적 ID와 연결되고 실제 단일·광역 공격 피해 정산에 적용된다.
- 중복 정의 ID, 알 수 없는 효과·적 참조, 같은 효과의 중복 연결, 직접·간접 순환 참조와 범위 밖 합성 결과를 거부한다.
- 외부 파일이 없거나 일부라도 잘못되면 부분 데이터를 사용하지 않고 내장 오브·유물 정의로 복구한다.
- 배포 패키지와 사전 검사에 `gameplay.v1.ini` 필수 포함 검증을 추가했다.
- 작성 규칙과 복구 정책을 `CONTENT.md`에 문서화했다.
