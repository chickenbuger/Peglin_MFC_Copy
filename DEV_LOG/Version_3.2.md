# Version 3.2 — 조준 예상선과 발사 세기 시각화

## 버전 정보

| 항목 | 값 |
| --- | --- |
| 버전 | Version 3.2 |
| 스프린트 | Sprint 3 |
| 작업일 | 2026-08-29 (Asia/Seoul) |
| 상태 | 구현 및 검증 완료 |

## 구현 이유

- 기존 조준선은 `Parent_ball`의 렌더링 안에서 별도로 계산되어 실제 발사 방향·힘과 일치하는지 모델 테스트를 할 수 없었다.
- 드래그 길이가 어느 정도의 발사 세기로 변환되는지 화면에서 알 수 없어 같은 조준을 반복하기 어려웠다.

## 구현 내용

- `GameWorld`가 조준 시작점과 현재 드래그 위치를 소유하고 `AimPreview` 값을 계산한다.
- 예상 방향은 실제 발사와 같은 `시작점 - 현재점` 정규화 벡터를 사용한다.
- 드래그 거리 1~400px를 실제 힘 1~10과 같은 규칙으로 변환하고 0~100% 세기로 노출한다.
- 16개 예상 지점에 중력과 좌·우 벽·천장 반사를 적용한다.
- 뷰는 예상 지점을 점선으로 연결하고 보드 왼쪽 위에 색상 변화가 있는 `POWER n%` 막대를 표시한다.
- 0 길이 입력, 발사 완료, 취소, 포커스 상실과 F5 초기화 시 예상선을 즉시 숨긴다.

## 자동화 검증

- 0 길이 조준에서 미리보기가 나타나지 않는지 확인했다.
- 오른쪽 220px 드래그가 왼쪽 발사 방향과 50% 세기를 만드는지 검증했다.
- 400px 드래그가 100%로 제한되고 실제 발사 속도 방향과 일치하는지 확인했다.
- 모든 예상점이 물리 벽 경계 안에 남고 F5 후 잔류하지 않는지 검증했다.
- Debug/Release × x64/x86 빌드 성공, 오류 0개, 프로젝트 자체 경고 0개다.
- `PeglinCoreTests`: 구성별 `227 PASS / 0 FAIL`, 네 구성 총 908개 통과다.

## 실제 실행 검증

- Release x64에서 220px 수평 드래그가 정상 발사로 연결됐다.
- 공이 예상한 반대 방향으로 이동하고 페그 적중·점수 정산이 유지됐다.
- 비행 중 F5가 공을 초기 위치와 조준 상태로 복귀시키고 이후 입력을 정상 수용했다.
- 오류 대화상자, ASSERT와 잔류 프로세스 없이 정상 종료했다.
