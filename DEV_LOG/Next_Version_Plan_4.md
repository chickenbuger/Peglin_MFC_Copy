## P0 — Sprint 4 완료 필수 후보

- [x] 설정 저장·불러오기 — Version 4.1
  - 이유: Sprint 3에서 추가한 난이도, 음소거와 색상 구분 설정이 현재는 앱을 종료하면 기본값으로 돌아간다.
  - 완료 기준: 사용자별 쓰기 가능한 경로에 버전이 있는 설정을 저장하고, 파일 누락·손상·알 수 없는 값에서는 안전한 기본값으로 복구한다.
- [x] 스테이지별 최고 점수·최고 콤보·클리어 기록 — Version 4.2
  - 이유: 결과 화면이 한 판의 성과만 보여 주어 재도전과 스테이지 선택의 장기 목표가 남지 않는다.
  - 완료 기준: 스테이지와 난이도별 기록을 저장하고 결과·선택 화면에 표시하며 더 낮은 기록으로 덮어쓰지 않는다.
- [x] 배포 패키징과 실행 전 사전 검사 — Version 4.3
  - 이유: 개발 PC에서는 MFC 구성요소가 설치되어 있지만 다른 Windows PC에서 Visual C++ 런타임과 자산 누락으로 실행이 실패할 수 있다.
  - 완료 기준: Release x64 실행 파일, 필수 자산과 런타임 정책을 재현 가능한 패키지로 만들고 깨끗한 설치 환경 점검 절차를 문서화한다.
- [x] 저장·배포 경로 자동화 테스트와 최종 회귀 — Version 4.4
  - 이유: 파일 I/O와 패키징은 정상 경로뿐 아니라 권한, 손상, 버전 변경과 누락 자산을 함께 검증해야 한다.
  - 완료 기준: 설정·기록의 생성, 갱신, 손상 복구와 데이터 마이그레이션을 자동화 테스트로 검증하고 전체 플레이·GDI 게이트를 통과한다.
