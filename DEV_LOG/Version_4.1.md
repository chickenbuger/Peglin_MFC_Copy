| 스프린트 | Sprint 4 |

| 판정 | **P0-1 완료** |

## 구현 내용

- 사용자별 `%LOCALAPPDATA%\PeglinMFC\settings.v1.ini`에 설정을 저장한다.
- 파일에 `peglin_settings_version=1`을 기록해 향후 형식 변경을 구분한다.
- 난이도, 사운드 활성화와 표준·고대비 페그 모드를 이름이 있는 값으로 직렬화한다.
- 옵션 화면과 인게임 음소거 변경 직후 임시 파일을 쓴 뒤 기존 파일을 교체한다.
- 앱 시작 시 설정을 불러오며 파일 누락·손상·지원하지 않는 버전·알 수 없는 값에서는 `보통 / 사운드 켜짐 / 표준 색상` 기본값으로 복구한다.
- 저장 실패는 게임 실행을 중단하지 않고 옵션 화면에 경고를 표시한다.
- 옵션 화면 하단에 자동 저장 상태와 돌아가기 안내가 실제 클라이언트 영역 안에 보이도록 배치를 조정했다.

## 검증

- Debug/Release × x64/x86 앱·테스트 빌드: 오류 0개, 프로젝트 자체 경고 0개.
- 구성별 `297 PASS / 0 FAIL`, 총 1,188개 검증 통과.
- 새 테스트 25개가 다음 경로를 검증한다.
  - 파일 누락 시 기본값 복구
  - 부모 폴더 생성과 최초 저장
  - 어려움·음소거·고대비 값 왕복
  - 기존 파일 교체 저장
  - 알 수 없는 값, 미지원 버전과 불완전 파일 거부
  - 디렉터리 생성을 막는 경로에서 예외 없는 저장 실패와 오류 보고
- Release x64에서 `어려움 / 사운드 꺼짐 / 고대비 + 모양`으로 변경 후 앱을 종료했다.
- 실제 설정 파일에 버전과 세 값이 기록된 것을 확인했다.
- 앱 재실행 시 stage-1 `HP 30 / 6 Steps`, stage-2 `HP 45 / 4 Steps`와 음소거·고대비 설정이 그대로 표시됐다.
- 검증 뒤 사용자 설정을 안전한 기본값으로 복원하고 게임 창을 정상 종료했다.
