## P0 — Sprint 5 완료 필수 후보

- [x] 오브와 유물의 데이터 모델·획득·적용 기반 — Version 5.1
  - 이유: 현재 모든 발사가 같은 규칙을 사용해 판마다 선택과 성장의 차이가 부족하다.
  - 완료 기준: 안정적인 ID를 가진 오브·유물 정의, 중복 정책, 효과 적용 순서와 초기화 규칙을 모델 계층에서 검증한다.
- [x] 다양한 적 행동과 보스 스테이지 — Version 5.2
  - 이유: 현재 적은 이동 후 고정 피해만 주므로 스테이지별 전술 차이가 작다.
  - 완료 기준: 최소 두 행동 유형과 보스 한 종을 데이터로 정의하고 예고·실행·승패·재시작을 결정적으로 검증한다.
- [x] 외부 데이터 기반 콘텐츠 로딩과 검증 — Version 5.3
  - 이유: 새 스테이지·적·오브를 추가할 때마다 C++ 재컴파일이 필요하면 콘텐츠 확장과 오류 격리가 어렵다.
  - 완료 기준: 버전이 있는 콘텐츠 파일을 안전한 경로에서 읽고 알 수 없는 ID, 중복, 범위 초과와 부분 손상을 거부한다.
- [ ] 공통 UI 테마·화면 구성 요소와 장비 선택 화면
  - 이유: 현재 화면별 GDI 코드와 키 안내가 흩어져 있고 오브·유물 상태를 확인하거나 선택할 전용 흐름이 없다.
  - 완료 기준: ImageGen으로 제작한 프로젝트 전용 배경을 리소스로 포함하고 공통 패널·제목·선택 강조·키 안내를 재사용하며, 키보드만으로 장비 선택과 화면 복귀가 가능해야 한다.
- [ ] 콘텐츠 조합 회귀와 전체 실행 검증
  - 이유: 오브·유물·적 행동이 결합되면 효과 순서와 저장 호환성에서 회귀 위험이 커진다.
  - 완료 기준: 네 구성 빌드·자동 테스트, 대표 승리·패배·재시작, 저장 마이그레이션과 10분 GDI 게이트를 모두 통과한다.

## P1 — P0 이후 후보

  - 이유: 누적 기록이 늘어나면 최고값만으로 플레이 패턴을 비교하기 어렵다.
