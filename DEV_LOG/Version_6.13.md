## 개선 이유

한국어 UI 문구가 뷰 코드에 직접 들어 있어 표시 언어를 바꾸거나 누락 문자열을 검사하기 어려웠다. ImageGen PNG 원본과 MFC GDI용 BMP 사이의 변환 절차도 수동이어서 크기, 색심도, 리소스 ID 불일치가 배포 직전까지 남을 수 있었다.

## 구현 결과

- `strings.ko-KR.v1.ini`, `strings.en-US.v1.ini`에 화면 제목, 옵션, 버튼 힌트, 난이도와 페그 색상 값을 UTF-8 키-값으로 분리했다.
- 외부 문자열의 버전·로케일·UTF-8·키·이스케이프를 검증하고, 누락된 키만 선택 언어의 내장 문구로 병합한다.
- 중복·알 수 없는 키, 잘못된 UTF-8, 로케일 불일치는 부분 적용 없이 내장 카탈로그로 복구한다.
- 옵션에 `언어` 항목을 추가해 키보드 `L`과 마우스 클릭으로 한국어↔영어를 즉시 전환하고, 설정 파일에 선택을 저장한다.
- 기존 Version 1 설정 파일은 언어 키가 없어도 한국어 기본값으로 호환한다.
- 앱과 테스트 모두 `/utf-8`로 컴파일하여 소스·외부 파일·`CString` 변환의 문자 집합을 일치시켰다.
- `assets.v1.json`에 8개 런타임 자산의 원본, BMP, 리소스 ID, 크기와 투명 규칙을 정의했다.
- `Build-Assets.ps1`이 PNG 원본 7개의 24-bit BMP 변환 가능성, 커밋된 BMP 8개의 크기·색심도, `UiResources.rc`의 ID·파일 연결을 자동 검증한다.
- 패키지에 두 언어 카탈로그를 포함하고, 누락·변조 시 사전 검사가 실패하도록 확장했다.
