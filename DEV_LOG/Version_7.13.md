## 개선 이유

기존 스테이지 선택 화면은 경로 이름이 들어간 넓은 텍스트 카드와 우측 규칙 패널 위주여서 서로 다른 선택지의 분위기를 빠르게 비교하기 어려웠다. 런의 전체 진행 위치도 작은 진행 막대로만 표현되어 다음 전투와 보스까지의 흐름이 약했다. 선택에 필요하지 않은 상세 규칙은 덜어내고 스테이지 일러스트, 유형, 선택 상태와 전체 경로를 중심으로 재구성했다.

## 구현 내용

- ImageGen으로 숲길, 수정 동굴, 버섯 습지, 용암 지대, 보스 성채의 스테이지 프리뷰 5종을 새로 제작했다.
- 각 프리뷰를 320×240 24-bit BMP로 변환해 MFC 리소스에 포함하고 스테이지 ID별 테마에 연결했다.
- 선택지 두 개는 좌우 이미지 카드로 나란히 배치하고 단일 고정 노드는 중앙 카드로 표시한다.
- 카드에는 스테이지 이름, `BATTLE`·`SHOP`·`BOSS` 유형과 선택 상태만 남겼다. `READY`, 과거 기록, 상세 규칙은 표시하지 않는다.
- 선택 카드는 시작 전까지 다시 클릭해 변경할 수 있으며 선택된 카드는 금색 또는 유형별 강조 테두리로 구분한다.
- 상단에 6개 노드 런 경로를 추가해 완료 노드는 녹색, 현재 노드는 금색, 이후 노드는 흐린 테두리로 표시한다.
- 기존 우측 규칙 패널을 제거하고 장비·옵션 버튼을 좌측 모험 상태 패널 아래에 모았다.
- 카드·시작·장비·옵션의 마우스 적중 영역을 새 배치와 일치시키고 자동화 테스트 좌표를 갱신했다.
- 상점 노드는 기존 고블린 상인 이미지를 프리뷰 카드에 재사용해 전투 노드와 시각적으로 구분했다.
