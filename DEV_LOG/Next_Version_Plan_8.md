## P0 — Sprint 8 완료 필수 후보

- [ ] DPI·해상도·창 크기 대응 레이아웃 — Version 8.1 후보
  - 이유: 현재 1,000×700 기준 절대 좌표 UI는 고DPI와 다른 창 크기에서 카드·클릭 영역이 어긋날 수 있다.
- [ ] 오브·유물·적 상세 툴팁과 전투 로그 — Version 8.2 후보
  - 이유: 정확한 효과 수치는 선택 화면에 있지만 전투 중 중첩·발동 순서와 적 행동 근거를 다시 확인하기 어렵다.
- [ ] 스테이지·게임플레이 콘텐츠 검증 리포트와 미리보기 도구 — Version 8.3 후보
  - 이유: 외부 INI 검증은 안전하지만 제작자가 배치·참조·난이도 결과를 게임 실행 전에 한눈에 확인할 수 없다.
- [ ] 게임패드 데드존·감도·버튼 설정과 실제 장비 QA — Version 8.4 후보
  - 이유: 전체 런 입력은 연결됐지만 장치별 스틱 편차와 사용자 선호를 조절할 수 없고 실제 장비 검증이 남았다.
- [ ] 오디오 믹싱·동시 재생 제한·장면 전환 페이드 — Version 8.5 후보
  - 이유: 개별 볼륨과 파일 카탈로그는 갖췄지만 다중 페그 충돌과 화면 전환에서 음량 밀도와 BGM 연결감을 더 다듬을 수 있다.
- [ ] 결정적 데모 런·포트폴리오 캡처 지원 — Version 8.6 후보
  - 이유: 기능 시연 영상을 반복 촬영할 때 같은 경로·전투 장면을 재현하고 핵심 기능을 빠르게 보여줄 수단이 필요하다.
- [ ] 성능 계측 HUD와 장시간 회귀 자동화 — Version 8.7 후보
  - 이유: GDI 안정성은 수동 표본으로 확인하지만 프레임 시간, 이벤트 수와 자원 추이를 재현 가능한 리포트로 남기기 어렵다.
- [ ] Sprint 8 결합 회귀·접근성·최종 배포 — Version 8.8 후보
  - 이유: 스케일링·도구·입력·오디오 변경을 전체 런과 패키지에서 함께 검증해야 한다.

## 진행 규칙

1. 사용자가 Sprint 8 시작을 명시한 뒤 Version 8.1부터 순서대로 진행한다.
2. 기능 하나당 `구현 → 네 구성 빌드·테스트 → 실행 검증 → Version 문서 → 커밋·푸시 → Notion`을 유지한다.
3. Sprint 종료 시 계획 전체 목록과 각 항목의 완료 여부를 반드시 표출한다.
4. P0와 검증 게이트를 모두 완료하기 전에는 Sprint 9로 이동하지 않는다.
