## 개선 이유

기존 스테이지는 페그의 위치와 종류만 달라 모든 페그가 정지해 있었다. 서로 다른 배치를 선택해도 발사 시점을 고려할 필요가 없고, 같은 조준을 반복하면 결과도 비슷해 스테이지별 플레이 감각이 충분히 달라지지 않았다. 일부 페그가 예측 가능한 경로로 계속 이동하도록 만들어 조준 타이밍과 충돌 경로에 변화를 주었다.

## 구현 내용

- `PegMotionKind`와 `PegMotionDefinition`을 추가해 페그마다 이동축, 진폭, 각속도와 시작 위상을 지정한다.
- 이동 페그는 고정 10ms 게임 루프의 누적 시간을 사용해 기준 위치에서 사인 곡선으로 왕복한다.
- 조준 중과 공 비행 중에는 계속 이동하며 일시정지 중에는 멈춘다.
- 스테이지 재시작 시 누적 시간을 초기화해 항상 같은 시작 위상과 위치를 재현한다.
- 실제 충돌은 이동한 현재 좌표를 사용하고, 조준 예상선은 예상 비행 시간의 미래 페그 위치를 사용한다.
- 이동 페그의 수평·수직 축을 알아볼 수 있도록 페그 양옆 또는 위아래에 청록색 이동 표식을 표시한다.
- Refresh 복원 판정을 좌표 비교에서 원본 페그 인덱스 비교로 변경했다. 이동 중인 활성 페그를 제거된 페그로 오인해 중복 복원하지 않는다.
- 외부 `stages.v1.ini`에 `peg_motion=인덱스,축,진폭,각속도,위상` 형식을 추가했다.
- 알 수 없는 축, 잘못된 수치, 중복 인덱스와 PEG FIELD 밖으로 나가는 이동 경로를 거부한다.
