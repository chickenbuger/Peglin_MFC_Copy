## 검증 목적

Sprint 7에서 추가한 분기형 런, 몬스터·Refresh·이동 페그, 상점, 오디오, 화면 애니메이션, 게임패드, 상세 통계와 세이브 복구가 함께 작동할 때의 회귀와 배포 누락 위험을 최종 확인했다.

## 전체 회귀 결과

- 여섯 계층 분기 런의 시작, 전투, 보상, 경로 변경·확정, 상점, 최종 보스, 승리·패배와 재도전을 결정적 모델 테스트로 재검증했다.
- 단일·광역 및 근접·원거리 공격, 모든 생존 몬스터의 이동과 개별 사거리 공격, Refresh Peg 최소 보장·매 턴 재배치·파괴 후 재생성을 결합 회귀에 포함했다.
- 오브 덱 전체 사용 후 리필, 다음 오브, 보상·상점 획득, 상세 통계 집계와 Version 0·1 기록 마이그레이션을 확인했다.
- 마우스·키보드·게임패드의 전체 화면 명령 매핑과 필수 보상 취소 방지를 재검증했다.
- 오디오 카탈로그 11개 WAV, 효과음·배경음 독립 볼륨, 설정 Version 0·1 마이그레이션과 세이브 백업·손상 복구·선택 초기화를 확인했다.
- 물리 게임패드 장비는 연결할 수 없어 실제 손맛·데드존은 자동 매핑 테스트와 미연결 런타임 안전성까지만 검증했다.
