## 구현

- 안정적인 문자열 ID를 가진 오브 3종을 추가했다.
  - `basic-orb`: 피해·점수 기본 배율
  - `iron-orb`: 페그 피해 150%, 점수 75%
  - `echo-orb`: 페그 피해 80%, 점수 150%
- 유물 3종과 중복 정책을 추가했다.
  - `combo-lantern`: 고유, 점수 125%
  - `thorn-charm`: 고유, 페그 피해 120%
  - `bark-guard`: 최대 2중첩, 중첩당 받는 피해 85%
- 효과 적용 순서를 `선택 오브 → 획득 순서의 유물 → 0.1~5.0 안전 범위 제한`으로 고정했다.
- 알 수 없는 ID, 고유 유물 중복과 최대 중첩 초과는 기존 장비를 변경하지 않고 거부한다.
- `GameWorld`가 장비 선택·획득·계산 결과를 소유하고 실제 페그 피해·점수·플레이어 피격에 반영한다.
- `ResetGame()` 재도전은 장비를 유지하고 `ResetProgression()`만 기본 오브·유물 없음 상태로 새 게임을 시작한다.

## 검증

- Debug/Release × x64/x86 앱·테스트 빌드 성공.
- 오류 0개, 프로젝트 자체 경고 0개.
- 구성별 `403 PASS / 0 FAIL`, 총 `1,612 PASS / 0 FAIL`.
- Iron Orb의 첫 일반 페그 결과가 피해 1.5, 점수 75로 정산됨을 확인했다.
- Bark Guard 2중첩이 기본 피해 20을 14.45로 줄이고 플레이어 체력을 85.55로 남겼다.
- 재도전 후 장비 유지와 명시적 진행 초기화 후 기본 장비 복귀를 확인했다.
