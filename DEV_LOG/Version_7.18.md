## 개선 이유

기존 기록은 스테이지와 난이도별 최고 점수·콤보·클리어 횟수만 저장해 어떤 오브가 안정적이었는지, 평균 성과가 높은 조합이 무엇인지 비교할 수 없었다. 포트폴리오에서도 실제 플레이 데이터가 누적·탐색되는 구조를 보여줄 전용 화면이 필요했다.

## 구현 내용

- 결과 요약에 마지막으로 발사한 오브 ID를 보존한다.
- `PerformanceRecord`를 추가해 스테이지·난이도·오브 조합별 시도, 클리어, 총점, 평균, 최고점과 최고 콤보를 누적한다.
- 기록 파일을 Version 2로 올리고 기존 Version 0·1 파일은 기존 스테이지 기록을 보존한 채 자동 마이그레이션한다.
- 상세 조합 중복, 음수·오버플로 값, 잘못된 ID, 클리어가 시도보다 많은 파일과 과대 레코드 수를 거부한다.
- 스테이지 선택 좌측에 `통계` 버튼을 추가하고 장비·옵션 버튼을 같은 세로 그리드로 정렬했다.
- 전용 통계 화면에 스테이지, 난이도, 오브, 시도, 클리어, 평균, 최고점과 콤보 열을 표시한다.
- 난이도는 전체·쉬움·보통·어려움으로 필터하고 최고점·클리어·평균점수로 정렬한다.
- 마우스, 키보드 `T/D/S/B`, 게임패드 포커스·A/B 입력을 모두 연결했다.
