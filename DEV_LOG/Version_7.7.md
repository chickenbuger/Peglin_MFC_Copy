## 개선 이유

오브와 유물은 서로 다른 효과를 가졌지만 메뉴와 보상 화면에서는 단순 도형 또는 텍스트만 보여 종류를 빠르게 구분하기 어려웠다. 보상 설명도 이름 중심이라 실제 피해·점수 배율, 공격 범위, 유물 중첩 방식과 최대 보유량을 획득 전에 판단하기 부족했다. 보상 선택 직후 화면이 바뀌어 어떤 효과가 적용됐는지 확인할 시간도 없었다.

## 구현 내용

- built-in ImageGen으로 오브 3종과 유물 3종의 투명 PNG 아이콘을 제작했다.
  - Traveler Orb, Iron Orb, Echo Orb
  - Combo Lantern, Thorn Charm, Bark Guard
- PNG 원본과 96×96 24-bit BMP 런타임 리소스를 `assets.v1.json`과 `UiResources.rc`에 등록했다.
- `OrbDefinition`, `RelicDefinition`에 안정적인 `imageKey`를 추가했다.
- 외부 `gameplay.v1.ini`에서 `icon` 키를 읽고 검증하도록 카탈로그 로더를 확장했다.
- 보상 효과 설명을 실제 데이터에서 생성하는 `RewardPresentation`을 추가했다.
  - 오브: 페그 피해·획득 점수의 배율과 증감률, 근접·원거리, 단일·모든 적, 덱 추가 규칙
  - 유물: 적용 배율, 고유·중첩 정책, 최대 보유량과 곱연산 결과
  - 회복: 회복량과 최대 체력 상한
- Bark Guard는 중첩당 `받는 피해 ×0.85 (-15%)`, 2중첩 `×0.7225 (-27.75%)`를 명시한다.
- 장비 화면, 전투의 현재·다음 오브 HUD, 스테이지 보상 카드에 실제 아이콘을 표시한다.
- 획득 한도에 도달한 오브·유물은 보상을 소비하지 않고 다른 보상을 선택하도록 안내한다.
- 보상 선택 후 1.25초 동안 아이콘·이름·적용 효과를 표시한 뒤 다음 경로 선택 화면으로 이동한다.
- 생성 프롬프트와 파일 연결을 `reward-item-icons-v1.prompt.md`에 기록했다.
