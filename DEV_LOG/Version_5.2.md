| 버전 | Version 5.2 |

| 판정 | **P0-2 완료** |

## 구현

- 적 행동을 `Advance`, `Fortify`, `Strike`의 데이터 정의로 분리했다.
- 세 번째 스테이지 `stage-3 / Rootbound Citadel`을 추가했다.
  - 체력 60, 전용 36페그 보드, 보스 표시
  - `48 이동 → 방어막 4 → 피해 18 → 피해 24`의 네 단계 반복 패턴
- 현재 턴 번호로 다음 행동을 결정하므로 예고와 실제 실행이 같은 데이터를 사용한다.
- 방어막은 턴에 누적된 페그 피해를 먼저 흡수하고 남은 피해만 적 체력과 정산 피드백에 반영한다.
- Easy/Hard 난이도는 공격 행동의 피해만 각각 75%/125%로 조정하며 이동·방어 값은 유지한다.
- 일반 스테이지는 기존의 이동 후 고정 피해 규칙을 그대로 사용해 이전 콘텐츠 동작을 보존했다.
- HUD에 다음 행동과 남은 방어막을 표시하고, 이동·방어 행동을 별도 게임 이벤트로 전달한다.
- 재도전은 방어막, 턴 인덱스와 다음 행동 예고를 첫 상태로 복원한다.

## 방어적 검증

- 보스인데 행동 패턴이 없는 정의를 거부한다.
- 알 수 없는 행동 종류와 0·음수·비정상 수치의 행동 크기를 거부한다.
- 난이도 적용 뒤에도 패턴 순서와 비공격 행동 값이 바뀌지 않음을 검증했다.

## 빌드·테스트

- Debug/Release × x64/x86 앱·테스트 빌드 성공.
- 네 구성 모두 오류 0개, 프로젝트 자체 경고 0개.
- 구성별 `452 PASS / 0 FAIL`, 총 `1,808 PASS / 0 FAIL`.
- 이동, 방어막 획득·흡수, 일반 공격, 강공격, 패턴 반복과 재시작 초기화를 모델 테스트로 확인했다.
- 기존 스테이지·점수·페그 효과·저장·기록·오브·유물 회귀 테스트도 모두 통과했다.
