## P0 — Sprint 2 완료 필수 후보

- [ ] 점수와 콤보 규칙을 `GameWorld`에 추가한다.
  - 이유: 현재 피해량만 표시되어 연속 충돌의 플레이 성과와 선택 차이가 충분히 드러나지 않는다.
  - 완료 기준: 페그 적중, 연속 적중과 턴 종료 점수가 순수 모델에서 계산되고 자동 테스트로 검증된다.
- [ ] 페그 종류와 효과를 데이터 정의로 확장한다.
  - 이유: 좌표만 데이터화된 현재 구조로는 폭발, 치명타, 새로고침 같은 Peglin형 선택지를 표현하기 어렵다.
  - 완료 기준: 페그 유형·시각 속성·충돌 효과가 데이터에서 생성되고 기본 페그 회귀 테스트를 유지한다.
- [ ] 스테이지 정의와 로딩 경로를 추가한다.
  - 이유: 사용자 정의 좌표를 코드에서 직접 주입할 수 있지만 여러 보드를 외부 콘텐츠처럼 관리하는 경로는 없다.
  - 완료 기준: 검증된 스테이지 데이터가 보드·적·턴 규칙을 구성하고 잘못된 데이터에 안전하게 실패한다.
- [ ] Sprint 2 핵심 규칙의 자동화 테스트를 확장한다.
  - 이유: 점수와 페그 효과 조합은 상태 수가 늘어나 수동 플레이만으로 회귀를 막기 어렵다.
  - 완료 기준: 점수, 콤보, 페그 효과, 스테이지 로딩과 승패 회귀가 네 구성에서 통과한다.
