# Version 0.14 — `/W4` 경고 0개 기준선

## 버전 정보

| 항목 | 값 |
| --- | --- |

## 변경 사항

- Debug/Release × x64/x86의 `WarningLevel`을 모두 `Level4`로 변경했다.
- 물리·보드 좌표는 `float`로 유지하고 GDI 호출 경계에서 `std::lround` 후 `int`로 명시 변환한다.
- RGB 매크로 인수의 부동소수점 리터럴을 정수로 교체했다.
- 입력 좌표의 `LONG→float` 변환을 명시하고 가려진 setter 매개 변수 이름을 수정했다.
- 충돌 반경 제곱을 직접 계산하고, 결과에 쓰이지 않던 페그 속도·법선 성분 지역 변수를 제거했다.
- 미사용 `OnEraseBkgnd` 매개 변수를 `UNREFERENCED_PARAMETER`로 명시했다.

## 검증

- Debug x64 `/W4` 경고 목록을 수집해 55개 자체 경고를 모두 제거했다.
- Debug/Release × x64/x86 네 구성 재빌드가 모두 오류 0개, 경고 0개로 성공했다.
- Debug x64와 Release x64에서 같은 좌표 `(492,326)→(430,226)` 드래그를 실행했다.
- 두 구성 모두 같은 방향으로 이동해 동일 페그 1개를 제거하고 몬스터 체력이 `20→19`가 된 뒤 공이 초기 위치로 복귀했다.
- 두 실행 파일 모두 오류 대화상자 없이 종료됐다.

## 결론

구성별 컴파일러 진단 차이를 제거했으며, 명시적 좌표 변환 뒤에도 Debug와 Release의 발사·충돌·턴 결과가 일치한다.
