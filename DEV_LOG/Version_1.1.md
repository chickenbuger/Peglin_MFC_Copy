## 변경 사항

- `GameState`에 `Aiming`, `BallInFlight`, `ResolvingTurn`, `Victory`, `Defeat`, `Paused`를 정의했다.
- `CanTransitionTo()`로 각 상태에서 허용하는 다음 상태를 한곳에 명시했다.
- 발사 성공 시에만 `Aiming → BallInFlight`로 전환한다.
- 공이 화면 아래로 이탈하면 `BallInFlight → ResolvingTurn`으로 전환하고 다음 고정 스텝에서 피해와 턴을 정산한다.
- 정산 결과에 따라 `Aiming`, `Victory`, `Defeat` 중 하나로 전환한다.
- `Space`는 현재 상태를 보존한 채 `Paused`로 이동하고, 다시 누르면 이전 조준 또는 비행 상태로 복귀한다.
- `F5`는 공과 누적 피해를 초기화하고 `Aiming`으로 복귀한다.
- 승패 중복 대화상자를 막던 범용 `check` 플래그를 제거하고 상태 자체가 단일 실행을 보장하도록 변경했다.

## 검증

- Debug/Release × x64/x86 네 구성 `/W4` 재빌드 성공: 오류 0개, 자체 코드 경고 0개.
- Debug x64 실제 창에서 드래그 발사, 페그 제거, 적 체력 `20→19`, 공 초기 위치 복귀를 확인했다.
- 비행 중 `Space` 입력 뒤 600ms 동안 공이 정지하고, 재개 뒤 비행과 턴 처리가 이어지는 것을 확인했다.
- 비행 중 `F5` 입력으로 공이 초기 위치로 돌아가고 즉시 다음 조준이 가능한 것을 확인했다.
- 오류 대화상자 없이 정상 종료했다.

## 결론

게임 흐름의 순서가 여러 플래그와 조건문의 우연한 조합이 아니라 검토 가능한 상태 전이 규칙으로 표현된다. 다음 단계에서는 이 상태 흐름이 호출하는 물리·전투 규칙을 `CChildView`에서 분리한다.
