# Version 0.7 — GDI 객체 수명 안정화

## 버전 정보

| 항목 | 값 |
| --- | --- |
| 버전 | Version 0.7 |
| 스프린트 | Sprint 0 |
| 작업일 | 2026-08-29 (Asia/Seoul) |
| 목적 | 프레임별 GDI 객체 선택 상태를 복원해 핸들 누수와 삭제 실패 방지 |
| 판정 | **GDI 선택 상태 복원 완료** |

## 변경 사항

- 배경, 플레이어, 적, 공과 페그의 `draw()`가 DC 상태를 `SaveDC/RestoreDC`로 보존한다.
- 브러시는 주소를 명시해 `SelectObject`에 전달한다.
- 공 그리기의 조기 반환을 제거해 활성 상태에서도 반드시 DC를 복원한다.
- 더블 버퍼용 비트맵을 선택하기 전 객체를 저장하고 `CBitmap` 파괴 전에 복원한다.

## 검증 기준

- Debug/Release × x64/x86 네 빌드 구성이 모두 성공했다.
- Debug x64 실행 화면에서 한글과 게임 객체가 기존과 동일하게 표시됨을 확인했다.
- 실행 중 GDI 객체 수를 30초 간격으로 측정한 결과 `31 → 34 → 35 → 34 → 31`개였으며, 지속 상승하지 않고 기준값으로 복귀했다.

## 결론

프레임마다 생성되는 GDI 객체가 DC에 선택된 채 파괴되는 경로를 제거했다. 단기 표본에서 GDI 객체 수가 안정적으로 유지돼 Version 0.7 검증을 통과했다. 최종 10분 안정성 측정은 Version 0.15에서 다시 수행한다.
