## 개선 이유

설정과 전투 기록은 잘못된 값을 안전하게 거부했지만, 현재 파일이 손상되면 마지막 정상 상태를 자동으로 복원할 수 없었다. 또한 사용자가 옵션만 기본값으로 되돌리거나 누적 기록만 지우려 해도 각각을 독립적으로 처리할 UI가 없었다.

## 구현 내용

- 정상 세이브를 교체하기 전에 직전 세대를 `.bak` 파일로 보존한다.
- 원본이 손상되거나 읽기 오류가 발생하면 백업도 동일한 파서로 먼저 검증하고, 정상 백업만 `.recovery` 임시 파일을 거쳐 원자적으로 복구한다.
- 손상된 원본을 새로 저장할 때는 기존 정상 백업을 손상 데이터로 덮어쓰지 않는다.
- 설정과 전투 기록의 불러오기 결과에 `Recovered` 상태를 추가해 자동 복구를 명시적으로 구분한다.
- 옵션 화면에 `설정만 초기화`와 `전투 기록 초기화`를 분리해 배치했다.
- 초기화는 마우스, 키보드, 게임패드에서 모두 접근할 수 있고, 3초 안에 같은 명령을 한 번 더 입력해야 실행되는 이중 확인을 적용했다.
- 선택 초기화는 대상 저장 파일, `.bak`, `.tmp`, `.recovery`만 삭제하고 다른 사용자 데이터에는 접근하지 않는다.
- 설정 초기화 후 오디오·언어를 즉시 기본값으로 반영하고, 기록 초기화 후 빈 기록 파일을 다시 안전하게 저장한다.
