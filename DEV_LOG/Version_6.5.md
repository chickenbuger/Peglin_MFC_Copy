## 개선 이유

스테이지 선택·장비·옵션·결과 화면은 키보드로만 이동할 수 있었다. 화면에는 카드와 버튼처럼 보이는 요소가 있었지만 마우스 클릭을 처리하지 않아 일반적인 UI 기대와 동작이 달랐다.

## 구현 결과

- `UiNavigation`에 화면별 클릭 영역과 의미 명령을 분리했다.
- 스테이지 카드 클릭으로 대상을 선택하고 하단 시작 버튼으로 플레이를 시작한다.
- 장비 관리와 옵션 버튼을 클릭해 각 화면으로 이동할 수 있다.
- 오브 카드 선택, 유물 획득, 장비 초기화와 뒤로가기를 클릭으로 수행한다.
- 난이도·사운드·페그 구분 옵션을 해당 패널 클릭으로 변경한다.
- 결과 화면의 다시 도전과 스테이지 선택도 독립 버튼으로 분리했다.
- 기존 방향키·숫자키·Enter·단축키와 동일한 게임 명령을 사용하므로 입력 방식에 따른 기능 차이가 없다.
- 클릭되지 않는 배경은 아무 명령도 발생시키지 않는다.
