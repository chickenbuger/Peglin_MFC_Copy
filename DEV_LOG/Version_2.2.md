# Version 2.2 — 데이터 기반 페그 종류와 효과

## 버전 정보

| 항목 | 값 |
| --- | --- |
| 버전 | Version 2.2 |
| 스프린트 | Sprint 2 |
| 날짜 | 2026-08-29 |
| 상태 | 구현 및 검증 완료 |

## 구현 이유

- 좌표만 가진 기존 페그 데이터로는 Peglin형 선택지인 치명타, 폭발과 보드 새로고침을 표현할 수 없었다.
- 효과 수치를 충돌 코드에 흩어 놓지 않고 데이터 정의에서 조회해야 새 스테이지와 추가 콘텐츠가 같은 규칙을 재사용할 수 있다.

## 페그 정의

| 종류 | 색상 | 피해 | 점수 | 충돌 효과 |
| --- | --- | ---: | ---: | --- |
| Normal | 빨강 | 1 | 기본 배수 ×1 | 단일 제거 |
| Critical | 노랑 | 2 | 배수 ×2 | 피해와 해당 적중 점수 2배 |
| Bomb | 검정 | 1 | 기본 배수 ×1 | 반경 100px 이내 페그도 함께 제거·보상 |
| Refresh | 초록 | 1 | 기본 배수 ×1 | 이전에 제거된 페그를 원래 종류로 복원, 자신은 제외 |

## 변경 사항

- `PegType`, `PegVisualStyle`, `PegTypeDefinition`, `PegDefinition`을 추가했다.
- `PegLayoutDefinition`이 좌표 목록 대신 종류를 포함한 페그 정의 목록을 보관한다.
- 기본 48개 보드를 Normal 44, Critical 2, Bomb 1, Refresh 1로 구성했다.
- 렌더러가 페그 종류의 시각 속성을 읽어 GDI 브러시 색상을 결정한다.
- `GameWorld`가 데이터에 정의된 피해·점수 배수·폭발 반경·복원 여부를 적용한다.
- 폭발로 제거된 각 페그도 피해, 콤보와 점수에 포함하되 추가 폭발·복원 효과는 연쇄 실행하지 않는다.
- 새로고침은 현재 활성 페그를 중복 생성하지 않고 제거된 페그만 원래 종류로 복원한다.

## 검증 결과

### 자동 검증

- Debug/Release × x64/x86 앱 및 테스트 빌드 성공
- 오류 0개, 프로젝트 자체 경고 0개
- `PeglinCoreTests`: 구성별 119 PASS, 0 FAIL, 총 476 PASS
- 종류별 시각 데이터, 피해, 점수 배수와 효과 설정 검증
- Critical: 첫 콤보 점수 200, 몬스터 피해 2 확인
- Bomb: 반경 안 2개 제거, 바깥 1개 유지, 콤보 점수 300과 피해 2 확인
- Refresh: 제거된 Normal 복원, 자신 제외, 원래 종류 유지 확인
- 기존 일반 페그, 반사, 점수, 턴과 승패 회귀 테스트 유지

### 실제 실행 검증

- x64 Release 기본 보드에서 빨강 44개, 노랑 2개, 검정 1개, 초록 1개의 구분 표시를 확인했다.
- 폭탄 방향 발사에서 폭탄과 인접 페그 묶음이 함께 제거되고 `적중 8 · 콤보 8 · 발사 3900`으로 반영됐다.
- 상단 피드백과 체력 문구가 겹치지 않고 게임 프로세스가 정상 종료됐다.
