# Version 0.10 — 화면 내부 12×4 페그 배치

## 버전 정보

| 항목 | 값 |
| --- | --- |
| 버전 | Version 0.10 |
| 스프린트 | Sprint 0 |
| 작업일 | 2026-08-29 (Asia/Seoul) |
| 목적 | 화면 밖에 생성되던 페그를 플레이 영역 내부 배열로 제한 |
| 판정 | **보드 배치 수정 완료** |

## 변경 사항

- 페그 열·행·시작점·간격을 이름 있는 상수로 정의했다.
- 페그를 80px 간격의 12열 × 4행, 총 48개로 생성한다.
- 중심 좌표 범위는 `x=50~930`, `y=400~640`이며 반지름 10px를 포함해도 플레이 영역 안에 남는다.
- 기존 열 개수와 실제 간격이 달라 화면 오른쪽 밖에 추가 객체를 만들던 수식을 제거했다.

## 검증

- Debug/Release × x64/x86 네 구성 재빌드 성공.
- Debug x64 실행 화면에서 12개 열과 4개 행, 총 48개 페그가 모두 표시됨을 확인했다.
- 가장 오른쪽 페그 중심 `x=930`과 가장 아래 페그 중심 `y=640`이 플레이 영역 안에 있음을 확인했다.
- 게임 창이 오류 대화상자 없이 정상 종료됐다.

## 결론

보드 데이터와 화면 표시가 일치하며, 충돌 목록에 화면 밖의 도달 불가능한 페그가 남지 않는다.
