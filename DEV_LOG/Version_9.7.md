## 개선 이유

기존 콘텐츠 보고서는 형식과 수치를 빠르게 검증할 수 있었지만, 페그 배치·이동 궤적·적 이미지가 실제 게임 화면에서 어떻게 보이는지는 매번 새 런을 시작해야 확인할 수 있었다. 또한 실행 중 파일을 다시 읽을 때 일부만 적용되면 현재 체크포인트와 보유 장비가 더 이상 유효하지 않을 수 있으므로, 적용 전 전체 호환성 검사와 원자적 교체가 필요했다.

## 구현 내용

- 스테이지 선택 화면에서 `F8`로 열 수 있는 전체 화면 콘텐츠 미리보기를 추가했다.
- `--content-preview` 실행 인수를 추가해 앱 시작과 동시에 미리보기를 열고 외부 콘텐츠를 다시 읽도록 했다.
- 실제 스테이지 배경, 적 이미지·체력·사거리, 일반·Refresh·Bomb 페그와 이동 궤적을 한 화면에서 확인한다.
- 키보드, 마우스와 게임패드로 이전/다음 스테이지 이동, 핫 리로드와 닫기를 동일하게 사용할 수 있다.
- 외부 스테이지와 게임플레이 카탈로그를 임시 객체로 읽고 교차 참조와 난이도 곡선이 모두 통과한 뒤에만 활성 상태를 교체한다.
- 진행 중인 런의 모든 전투 스테이지 ID와 보유·선호 오브, 획득 유물 ID가 새 카탈로그에 남아 있는지 확인한다.
- 실패 시 기존 스테이지, 게임플레이 규칙, 선택 화면과 로드아웃을 그대로 유지하고 원인을 미리보기와 창 제목에 표시한다.
- 성공한 새 경로 구조는 진행 중인 런을 바꾸지 않고 다음 새 게임부터 적용한다.
- 콘텐츠 확장으로 늘어난 5개 오브와 5개 유물을 로드아웃 화면에서 모두 선택할 수 있도록 카드, 숫자 단축키, 마우스와 게임패드 탐색 범위를 확장했다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `F8` | 스테이지 선택 화면에서 미리보기 열기·닫기 |
| `←` / `→` | 이전·다음 스테이지 |
| `R` | 외부 콘텐츠 핫 리로드 |
| `Esc` | 미리보기 닫기 |
| 게임패드 방향 / `A` / `B` | 스테이지 이동 / 리로드 / 닫기 |
| 화면 버튼 | Previous / Next / Hot Reload / Close |
