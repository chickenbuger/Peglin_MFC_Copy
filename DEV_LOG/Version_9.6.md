## 개선 이유

기존 런은 7개의 일반 전투 후보와 보스 1개로 끝까지 진행할 수 있었지만, 후반 조우와 빌드 선택이 반복될 여지가 컸다. 콘텐츠를 단순히 늘리기만 하면 특정 분기만 지나치게 쉽거나 어려워질 수 있으므로, 적 방어 효과와 공격 사거리, 이동 페그를 함께 반영하는 자동 난이도 검증이 필요했다.

## 구현 내용

- 일반 전투 `Obsidian Burrow(stage-9)`와 `Rootspire Crossing(stage-10)`을 추가했다.
- Cinder Beetle과 Root Lancer 시각 타입을 추가하고, 각 적의 체력·방어·공격 사거리를 외부 카탈로그에 연결했다.
- Cinder Orb, Verdant Orb, Ember Heart, Wayfinder Compass를 추가했다.
- 전투 완료 횟수 4단계 순환으로 신규 오브·유물이 보상에 실제 등장하도록 확장했다.
- 일반 전투 5층, 상점 1층, 보스 1층의 7층 런 경로를 구성했다.
- 적 유효 체력, 플레이어 피해, 적 수, 평균 공격 사거리, 이동 페그 수와 접근 압박을 합산하는 `DifficultyCurve` 분석기를 추가했다.
- 인접 스테이지 급등·급락, 같은 층 분기 불균형, 층 평균 역행, 보스 강도 범위를 자동 실패 조건으로 만들었다.
- 콘텐츠 보고서에 유효 체력과 난이도 점수, 판정 기준과 실패 이유를 기록한다.

## 이미지 자산

ImageGen의 기본 이미지 생성 모드로 현재 동굴 판타지 UI 분위기에 맞춘 투명 배경 자산 6개를 새로 제작했다.

- 적: `enemy-cinder-beetle-v1-source.png`, `enemy-root-lancer-v1-source.png`
- 오브: `orb-cinder-v1-source.png`, `orb-verdant-v1-source.png`
- 유물: `relic-ember-heart-v1-source.png`, `relic-wayfinder-v1-source.png`
- 프롬프트 방향: 어두운 동굴 판타지, 손으로 그린 게임 아이콘/스프라이트, 기존 청록·호박색 UI 팔레트, 읽기 쉬운 단일 실루엣, 글자와 프레임 없음
- 자산 파이프라인에서 MFC용 24-bit BMP와 마젠타 투명 키로 변환하고 RC 리소스 참조까지 검증했다.
