## 개선 이유

키보드와 마우스로는 전체 런을 진행할 수 있었지만 게임패드는 지원하지 않아 거실 PC와 휴대형 Windows 기기에서 선택·조준·발사를 이어갈 수 없었다. 입력 장치에 따라 접근 가능한 기능이 달라지지 않도록 모든 화면의 포커스와 전투 조작을 XInput에 연결했다.

## 구현 내용

- XInput 0번 컨트롤러를 고정 10ms 게임 루프에서 폴링하고 연결·해제 상태를 안전하게 처리한다.
- D-pad와 왼쪽 스틱으로 포커스를 앞·뒤 순환하며 끝에서 반대편으로 래핑한다.
- 스테이지, 장비, 옵션, 보상, 상점과 결과 화면의 모든 동작을 A 버튼에 매핑했다.
- B 버튼은 장비·옵션·결과에서 돌아가기, 상점에서 나가기로 동작하며 필수 보상 화면은 건너뛸 수 없다.
- 현재 포커스 카드에 4px 금색 테두리와 `[A]` 확인 배지를 표시한다.
- 전투 중 왼쪽 스틱으로 조준 예상선을 이동하고 A 또는 오른쪽 트리거로 발사한다.
- B는 진행 중인 조준을 취소하고 Start는 일시정지·재개한다.
- 메뉴 전환 시 포커스를 첫 항목으로 초기화하고 마우스·키보드 입력 경로는 그대로 유지한다.
