## 개선 이유

기존 효과음은 짧은 시간에 여러 페그가 충돌하면 `PlaySoundW` 호출이 계속 이전 소리를 덮어써 음이 잘리거나 거칠게 들릴 수 있었다. 화면이 바뀔 때 BGM도 즉시 정지·재생되어 장면 연결이 갑작스러웠다.

## 구현 내용

- 동일한 `peg_hit` 효과음을 55ms 안에 다시 요청하면 하나로 합치고, 일반 효과음은 100ms당 최대 3개만 재생한다.
- 폭탄, Refresh, 플레이어 피해, 승리와 패배 효과음은 일반 효과음 폭주 제한과 관계없이 우선 재생한다.
- 모험·상점·전투 BGM 전환 시 0.28초 페이드 아웃 후 새 곡을 0부터 페이드 인한다.
- 전환 도중 원래 화면으로 돌아오면 불필요한 곡 재시작을 취소하고 현재 음악을 다시 올린다.
- 음악 볼륨 명령은 실제 단계 값이 바뀔 때만 보내고, 음소거·0 볼륨·종료는 즉시 안전하게 닫는다.
- 효과음 제한과 페이드 보간을 Windows 재생 API와 분리해 결정적으로 자동 검증할 수 있게 했다.
