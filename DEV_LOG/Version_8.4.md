## 개선 이유

기존 게임패드 조준은 35% 고정 임계값과 단일 발사 길이를 사용하고 A 버튼·오른쪽 트리거가 동시에 발사로 동작했다. 장치별 스틱 드리프트와 사용자의 조작 선호를 반영할 수 없고 실제 연결 상태도 UI에서 알 수 없었다.

## 구현 내용

- 옵션 화면을 3×3 타일로 재배치하고 패드 데드존 15/25/35%, 감도 75/100/125/150%, 발사 버튼 A/오른쪽 트리거 설정을 추가했다.
- 방사형 데드존 밖의 입력을 0~1로 다시 정규화한 뒤 감도를 적용해 작은 드리프트는 제거하고 유효 입력은 끊기지 않게 했다.
- 튜닝된 스틱 세기에 따라 조준 드래그 길이가 100~200px로 변해 약한 입력과 강한 입력의 발사 세기가 구분된다.
- 선택한 발사 버튼만 공을 발사하도록 A 버튼과 오른쪽 트리거의 중복 동작을 제거했다.
- 설정 파일을 Version 3으로 올리고 Version 2는 기존 설정을 보존하면서 안전한 패드 기본값으로 마이그레이션한다.
- 옵션 화면에 `GAMEPAD 연결됨/미연결` 상태를 표시하고, 연결 해제 시 버튼·트리거·스틱 래치를 초기화한다.
