## 검증 목적

Sprint 6에서 추가한 다중 몬스터, 런 보상, 오브 덱, 공격 연출, 외부 효과, 지역화와 자산 파이프라인이 함께 작동할 때의 회귀 위험을 최종 실행·자원·배포 게이트로 확인했다.

## 최종 회귀 결과

- 순차 스테이지, 보상 선택, 오브 전체 사용 후 리필과 다음 오브 미리보기를 결정적 시드로 재검증했다.
- 외부 보스 스테이지, 광역 원거리 오브와 피해·점수·방어 유물 3종의 합성 순서를 고정했다.
- 대표 결합 런은 Victory 단일 결과, 재도전 후 보스 체력·행동·방어막 복원, 장비 유지, 결정적 Defeat 턴과 새 진행 초기화까지 통과했다.
- 예전 설정·기록 버전, 누락·손상 카탈로그 복구, 잘못된 외부 참조 거부와 패키지 누락 탐지를 모두 재실행했다.

## 실제 Release 플레이 확인

1. 스테이지 선택에서 `Forgotten Forest`에 진입했다.
2. 현재·다음 오브, 적 3마리의 개별 HP 막대와 페그 필드 배치를 확인했다.
3. 공을 드래그해 발사하고 페그 3개 적중, 적 피해 3, 턴 점수 1,000, 현재·다음 오브 교체를 확인했다.
4. `F5`로 비행 상태와 공을 조준 상태로 안전하게 복원한 뒤 창을 정상 종료했다.

## GDI 안정성

- 대상: Release x64 실제 전투 화면, 프로세스 응답 상태 유지
- 절차: 30초 워밍업 후 0~10분, 1분 간격 11개 표본
- GDI 표본: `43, 47, 43, 46, 43, 43, 43, 46, 46, 46, 46`
- USER 객체: `52~53`
- 결과: 기준 43→마지막 46, `+3`으로 허용 기준 `+5` 이내
- 후반 5개 표본이 지속 상승하지 않아 누수 조건을 통과했다.
