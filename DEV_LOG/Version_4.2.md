## 구현 내용

- `%LOCALAPPDATA%\PeglinMFC\records.v1.ini`에 버전이 있는 플레이 기록을 별도로 저장한다.
- 기록 키는 `스테이지 ID + 난이도`이며 최고 점수, 최고 콤보와 클리어 횟수를 보관한다.
- 최고 점수와 최고 콤보는 더 높은 값으로만 갱신하고 낮은 결과가 기존 기록을 덮어쓰지 않는다.
- 패배 결과도 점수·콤보 최고 기록 후보가 되지만 클리어 횟수는 승리 때만 증가한다.
- 선택 화면은 현재 선택한 난이도에 해당하는 두 스테이지 기록을 함께 표시한다.
- 결과 화면은 이번 결과 아래에 누적 최고 점수·콤보·클리어 횟수를 표시한다.
- 기록 파일의 잘못된 버전·난이도·음수·중복 키·비정상 스테이지 ID를 전체 거부하고 부분 데이터는 노출하지 않는다.
- 기록 저장 실패 시 현재 실행의 메모리 기록은 유지하고 결과 화면에 경고를 표시한다.

## 검증

- Debug/Release × x64/x86 앱·테스트 빌드: 오류 0개, 프로젝트 자체 경고 0개.
- 구성별 `342 PASS / 0 FAIL`, 총 1,368개 검증 통과.
- 새 테스트 45개가 다음 동작을 검증한다.
  - 최초 기록, 더 낮은 결과 보존과 더 높은 결과 갱신
  - 패배와 승리의 클리어 횟수 구분
  - 스테이지·난이도별 기록 격리
  - 파일 저장·불러오기·교체 저장
  - 미지원 버전, 알 수 없는 난이도, 음수와 중복 키 거부
  - 잘못된 파일에서 부분 기록 미노출과 저장 실패 보고
- 실제 Release x64에서 stage-1을 5턴에 클리어해 점수 8,800, 최고 콤보 10, 클리어 1을 기록했다.
- 결과 화면에 `RECORD 8800 · COMBO 10 · CLEARS 1`이 표시됐다.
- 선택 화면 복귀와 앱 재실행 후에도 stage-1 보통 난이도 기록이 유지됐고 stage-2 기록은 0으로 격리됐다.
- 실제 기록 파일은 `record=stage-1|normal|8800|10|1`로 저장됐다.
