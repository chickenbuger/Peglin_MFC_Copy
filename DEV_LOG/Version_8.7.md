## 개선 이유

기존 GDI 안정성 검증은 별도 도구에서 객체 수를 수동으로 읽어야 했고 프레임 지연과 고정 스텝 누적은 게임 화면에서 확인할 수 없었다. UI·오디오·데모 변경이 장시간 실행에서 자원을 계속 증가시키지 않는지 같은 절차로 반복할 자동화도 필요했다.

## 구현 내용

- `F3`으로 켜고 끄는 성능 HUD에 최근 240개 표본 기준 FPS, 평균·최대 프레임 시간, 현재·최대 고정 스텝을 표시한다.
- 현재 프로세스의 GDI와 USER 객체 수를 HUD에서 함께 표시해 화면 전환 중 누수를 즉시 관찰할 수 있다.
- 프레임 표본은 고정 용량 순환 버퍼를 사용해 성능 계측 자체가 장시간 메모리를 증가시키지 않는다.
- `tools/Test-LongRun.ps1`은 Release 데모를 숨김 실행하고 GDI, USER, 전체 핸들, Working Set과 Private 메모리를 일정 간격으로 기록한다.
- 첫·마지막 표본의 GDI/USER 증가 5개 이하, 전체 핸들 증가 10개 이하를 자동 합격 기준으로 사용하고 Markdown 리포트를 생성한다.
