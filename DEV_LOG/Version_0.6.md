# Version 0.6 — 공 상태 완전 초기화

## 버전 정보

| 항목 | 값 |
| --- | --- |
| 버전 | Version 0.6 |
| 스프린트 | Sprint 0 |
| 작업일 | 2026-08-29 (Asia/Seoul) |
| 목적 | F5·턴 종료·새 게임 이후 이전 발사 상태가 다음 입력에 섞이지 않도록 보장 |
| 판정 | **공 상태 초기화 개선 완료** |

## 변경 사항

- 초기 위치를 `INITIAL_X`, `INITIAL_Y` 상수로 통합했다.
- 생성자도 `Init()`을 사용해 런타임 초기화와 같은 기준을 따른다.
- 위치, 시작·추적·종료 드래그 좌표를 모두 초기 위치로 복원한다.
- 힘, x/y 속도, 활성화, 클릭, 정지 및 충돌 상태를 초기값으로 복원한다.

## 검증 기준

- 이동 중 `F5` 후 공이 시작 위치로 복귀함 — 통과
- 초기화 직후 반대 방향 드래그를 적용하자 이전 속도 없이 새 방향으로 이동함 — 통과
- 새 게임은 기존 Version 0.3 스모크 테스트와 동일하게 전체 상태를 복원함 — 통과
- Debug/Release × x64/x86 네 구성 재빌드 성공 — 통과

## 결론

공 초기화가 위치만 바꾸던 상태에서 전체 물리·입력 상태를 복원하는 동작으로 변경됐다.
