## 개선 이유

기존 화면은 개별 기능을 계속 추가하며 전투 상단에 플레이어 HP, 현재 상태, 타깃 HP와 행동 문구가 중복됐고 일부 정보가 몬스터 체력 막대와 가까워졌다. 메뉴 화면도 제목 크기·위치, 카드 간격과 버튼 기준선이 서로 달라 화면을 이동할 때 시선이 다시 정렬되어야 했다. Steam Peglin의 공식 게임 화면에서 확인한 큰 플레이필드, 한쪽에 고정된 오브 정보, 짧은 상단 상태 표시와 아이콘 중심 선택 원칙을 현재 어두운 동굴·금색·청록 테마에 맞게 적용했다.

## 참고한 UI 원칙

- 전투 장면과 페그 필드를 가장 큰 시각 영역으로 유지한다.
- 현재·다음 오브와 덱 상태는 한쪽 사이드 영역에 고정한다.
- 체력·골드·층·타깃 행동처럼 자주 확인하는 정보는 짧은 막대와 칩으로 표시한다.
- 보상·상점·장비는 큰 아이콘, 이름, 핵심 효과 순서로 읽히게 한다.
- 지도 진행은 상세 기록보다 현재 위치와 다음 선택지를 먼저 보여준다.
- 원작 이미지나 UI 자산은 복제하지 않고 정보 계층과 배치 원칙만 참고한다.

## 구현 내용

### 공통 메뉴

- 스테이지, 장비, 옵션, 보상, 상점과 결과 화면에 동일한 340×58 제목 배너를 적용했다.
- 제목을 배경 램프 위 원문 텍스트로 직접 출력하지 않고 어두운 패널과 금색 또는 화면별 강조색 안에 배치했다.
- 하단 주요 버튼의 높이와 기준선을 통일해 화면 이동 시 클릭 위치가 예측 가능하게 했다.

### 스테이지 선택

- 좌측 `ADVENTURE` 패널을 `FLOOR → HP 막대 → GOLD → CURRENT ORB → RELICS` 순서로 재구성했다.
- 현재 오브 실제 아이콘을 상태 패널에 표시하고 이름·유물 요약의 글자 크기와 여백을 조정했다.
- 기존 이미지 카드와 6노드 경로는 유지하면서 제목 배너와 좌측 상태 계층을 정렬했다.

### 전투 HUD

- 플레이어 HP 원문 텍스트를 실제 진행 막대로 교체하고 골드와 현재 런 노드를 아래에 배치했다.
- 중앙의 상태·점수·옵션 문구를 하나의 정보 패널로 묶었다. 게임 옵션에서 인게임 정보를 끄면 이 패널만 숨겨진다.
- 우측 상단에는 활성 타깃 이름, 남은 몬스터 수, 거리·사거리와 다음 행동만 표시한다.
- 활성 적 HP는 각 몬스터의 기존 체력 막대만 사용해 상단의 중복 HP 문구를 제거했다.
- 세 상단 패널의 하단을 몬스터 체력 막대보다 위에 제한해 캐릭터와 정보가 겹치지 않게 했다.

### 장비·옵션·보상·상점·결과

- 장비 화면을 `ORB BAG`과 `RELICS` 두 구획으로 나누고 3×2 카드의 아이콘·제목·효과 여백을 확대했다.
- 옵션을 긴 4행 목록에서 2×2 타일로 변경하고 라벨과 현재 값을 두 단계로 분리했다.
- 보상 카드를 세로로 확장해 아이콘과 실제 효과 설명 영역을 넓히고 상단에 HP·골드를 고정했다.
- 상점 상품을 3개의 동일 폭 카드로 정렬하고 가격·아이콘·효과·구매 상태 순서를 통일했다.
- 결과 화면의 제목·요약 패널·재시도·새 런 버튼을 같은 중심축에 정렬했다.

### 입력 정합성

- 변경된 장비, 옵션, 보상, 상점과 결과 화면의 모든 마우스 적중 영역을 실제 카드 좌표와 동기화했다.
- 2×2 옵션 타일 네 항목, 돌아가기 버튼과 비대화형 상태 영역을 별도 자동화 테스트로 검증했다.
- 결과 화면의 재시도와 새 런 버튼을 각각 독립적으로 검증했다.
